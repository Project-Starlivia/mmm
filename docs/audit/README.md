# 監査とリファクタの記録

**ここにあるのは過去の記録で、現在の姿ではない。** 当時のパス・用語・
ファイル名のまま残してある（書き換えると「その時なにが真だったか」が
失われるため）。今のコードの姿はリポジトリのルートの README を見ること。

生の測定出力と、同じ内容の重複（`raw/`・`phase1.json`・`perf-*.json`・
検討用の html）は 2026-08-24 に捨てた。**作業中の苦闘の How は要らない。
残すのは Why だけ**という方針に合わせたもので、中身は git の履歴にある。

## 安全に関わる指摘は、すべて閉じている

`FINDINGS-phase5.md` と `SUMMARY.md` にある「悪意ある `.md` が任意の
ファイルを読ませ、書き出した SVG に埋め込ませる」系の指摘は、当時の
再現手順ごと残してあるが**もう再現しない**。当時の Tauri / 親フォルダ許可の
前提そのものが無くなっているうえ、現在は 3 つの門で塞いである:

- **フォルダの外へは出ない** — `assetTarget` が `.` / `..` を含むパスを弾く
- **見に行くのは、宣言した保存パスの下だけ** — 2026-08-23 の Web 化で、
  「許可した親フォルダの配下すべて」ではなくなった
- **絵でないものは読まない** — `imageType` を通らない名前は弾く
  （`![](notes.txt)` はマップに何も出ないまま中身が SVG に載っていた。
  2026-08-27 に closed）

いずれも `src/app/assets.ts` と `test/assets.test.ts` にある。

## この記録より後に変わったこと

記録の中では現役の前提として書かれているが、**もう無い**もの:

- **「束(bundle)」というグルーピング** … 廃止（2026-08-14）
- **`---` による左右の振り分け** … 廃止。`---` はただの本文の行で、
  構造には一切効かない。マップは片側だけで、ルートは左端から右へ伸びる
- **Tauri / Rust** … 2026-08-23 に Web へ戻した（`docs/web.md`）。
  Shift-JIS・CRLF の往復と外部変更の監視も一緒に無くなった
- **`PERF.md` の計測ハーネス** … Playwright を使う 3 本のスクリプトは
  リポジトリ外の環境に依存していて動かなくなっていたので捨てた。
  いまは追加の依存なしで走る `pnpm run perf`（`test/tools/perf.ts`）が
  コアの物差しを出す。ブラウザのフレーム時間は測っていない

`DEBT.md` / `MAP.md` / `FINDINGS-phase5.md` は分量が大きく、上記の変更を
どれも反映していない。**現状の判断には使えない**ので、読むときは
「2026-08-10 に何が見えていたか」としてだけ読むこと。
