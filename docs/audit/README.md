# 監査とリファクタの記録

**ここにあるのは過去の記録で、現在の姿ではない。** 当時のパス・用語・
ファイル名のまま残してある（書き換えると「その時なにが真だったか」が
失われるため）。今のコードの姿はリポジトリのルートの README を見ること。

とくに次の 2 つは、記録の中では現役の前提として書かれているが**もう無い**:

- `audit/` … テストは `test/`、記録は `docs/audit/`（このディレクトリ）へ分かれた
- 「束(bundle)」というグルーピングの概念 … 廃止された。`---` は
  「そこから下の左右が入れ替わる」印だけを意味する（2026-08-14）

| ファイル | 何の記録か |
|---|---|
| `FIXES-2026-08-13.md` | いちばん新しい。バグ潰し・階層化・`---` の作り直しの経緯と結果 |
| `PERF.md` | 性能の計測方法と結果。**手順は現役**（`test/tools/perf*.ts`） |
| `SUMMARY.md` / `PROGRESS.md` | 2026-08-10 の監査の総括と進行 |
| `FINDINGS.md` / `FINDINGS-phase5.md` | 同、指摘の一覧（phase5 は生に近い） |
| `DEBT.md` | 同、技術的負債の棚卸し |
| `MAP.md` | 同、当時のコードの地図 |
| `identity-matrix.md` | ノード id の保存/消失の実測マトリクス |
| `phase1.json` / `perf-*.json` / `raw/` | ワークフローと計測の生出力 |
| `edge-styles.html` / `group-looks.html` | 線とグルーピングの見た目の検討用 |
