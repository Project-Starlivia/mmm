# キーボードショートカット

キーだけを集めた早見。**なぜそのキーなのか**（ブラウザの予約との兼ね合いなど）は
[spec.md](spec.md) の各節にある。ここは「どこで何が効くか」だけを言う。

`Mod` は `Ctrl` / `Cmd` どちらでも同じ。大文字のキー（`Shift+H` など）は
**実際に Shift を押している**ときだけ効く — CapsLock で `h` が `H` になっても
別のキーには化けない。

マウス・ドラッグ・ホイールでの操作（クリックの修飾や矩形選択など）は、
文脈と絡むため spec.md 側にある。

## 全体

どこにフォーカスがあっても効く（`src/app/shortcuts.ts`）。

| キー | 動作 |
|---|---|
| `Mod+Alt+N` | New |
| `Mod+O` | Open |
| `Mod+S` | Save |
| `Mod+Shift+S` | Save as |
| `Mod+E` | Export（いまの出し方でそのまま） |
| `Mod+Shift+E` | Export（ラジアルメニューで出し方を選び直す） |
| `Mod+Z` | Undo |
| `Mod+Shift+Z` / `Mod+Y` | Redo |
| `Mod+/` | Markdown と Mindmap でフォーカスを移す |
| `Alt+1` | Markdown の表示/非表示 |
| `Alt+2` | Mindmap の表示/非表示 |

Undo / Redo と表示の切り替えは、その場の入力欄（ラベル・カードの編集中など）が
開いている間は動かない・その欄自身の取り消しに譲る箇所がある。詳しくは各節。

## Mindmap

Mindmap の中だけで効く（`src/mindmap.ts`）。

**編集**

| キー | 動作 |
|---|---|
| `Mod+Enter` | 編集開始(カーソルは末尾) / 編集確定 |
| `Enter` | 編集確定 |
| `Esc` | 編集確定 |

**新規作成**

| キー | 動作 |
|---|---|
| `Enter` | 下の兄弟を作って編集開始 |
| `Shift+Enter` | 上の兄弟を作って編集開始 |
| `Tab` | 子要素を作って編集開始 |
| `Shift+Tab` | 親要素を作成(現ノードを包む)して編集開始 |

**構造・選択**

| キー | 動作 |
|---|---|
| `Tab` / `Shift+Tab`(複数選択) | 1 段下げ / 1 段上げ |
| `Delete` / `Backspace` | 削除(子ごと、複数可) |
| `Alt+↑↓` | 並べ替え(同じ親の中で) |
| `↑↓` / `←→` | 同じ深さの列を上下移動 / 親・子へ(左の枝では画面の向きどおり) |
| `Shift+矢印` | 移動と同じ道筋で選択を伸ばす |
| `Mod+A` | 全選択 |
| `Mod+C` | コピー |
| `Mod+X` | カット |
| `Mod+V` | 貼り付け |
| `Shift+H` | ノードを畳む / 展開(`<details>`) |
| `Shift+D` | その場で描いて、画像としてそのノードに貼る |
| `Shift+L` | クリップボードの URL をリンクとして貼る |
| `Shift+C` | 空のコードブロックを足して、その場で打てる状態にする |
| `Home` | 選択(無ければルート)を画面の中心へ寄せる(拡大率は変えない) |
| `Esc` | 選択解除 |

## カード

コンテンツカード(リンク / コード / SVG / 画像)を選んでいる間だけ効く。

| キー | 動作 |
|---|---|
| `Mod+Enter` | その場で編集 |
| `↑↓` | 隣のカードへ(端で止まる) |
| `←` | 持ち主のノードへ |
| `Alt+↑↓` | 並べ替え(端で止まる) |
| `Delete` / `Backspace` | 削除 |
| `Esc` | 編集の確定(その場編集中) |

## 描く窓

`Shift+D` で開く、その場で描くための窓の中だけで効く。

| キー | 動作 |
|---|---|
| `Mod+Z` | 一筆ずつ取り消し |
| `Mod+Enter` | 確定 |
| `Esc` | 破棄 |
