# mmm が捨てた自由と、取った自由

## 引っかかり

> マインドマップは本来自由なもので、画像もお絵描きも自在にできるべきだ
> — vs —
> エンジニアにそんなものは要らない。じゃあ普通に md を書いていろ

この問いは何度でも戻ってくる。描く道具を足すたび・削るたびに再燃するので、
決着をここに置く。

## 自由は 1 つの物ではない

分けると 2 つある。

- **空間性** — 全体が一望できる。枝を掴んで動かせる。親子と距離が目に見える
- **表現の自由** — どこにでも描ける。色を塗れる。画像を好きな場所に置ける

「md に書くより、マップのほうが整理しやすい気がする」の正体は**空間性だけ**。
整理しやすいのは描けるからではなく、**構造が物体になっている**から。md では
構造の編集が行の切り貼りという間接操作になり、マップはそれを直接掴ませる。

そして表現の自由は、むしろ**整理の敵**である。どこにでも置けるものは、どこに
あるか分からなくなる。共同のボードが数週間で腐るのはこれが理由。Buzan 流の
「絵を描け・色を塗れ」は記憶術（1 枚を描き上げて覚える）の文脈で言われたもので、
**維持し続ける道具**の文脈ではない。

## mmm が取ったもの

**mmm は自由なマインドマップではない。md を掴めるようにしたものである。**

「テキストが唯一の真実」と決めた時点で表現の自由は捨て、空間性を取っている。
つまりジレンマは創業時に解けていて、たまに片方への未練が疼いているだけ。

## そこから自動的に決まること

- 絵は**キャンバスの装飾になれない**。ノードの内容（カード）にしかなれない。
  自由に置けないからこそ、貼ったものが行方不明にならない
- 画像を「配置できる要素」にしない。許した瞬間に z 順・レイアウト・要素選択が
  芋づるで要り、ホワイトボードの再発明が始まる
- ノードの外に落とされた画像を受け取らないのも、同じ 1 つの理由

## 描く窓（draw）の位置づけ

2026-08-27 に外の地形を調べた。

- **構造系（XMind / MindNode / MindMeister）は描画を持たない。** 手描きが在るのは
  ホワイトボード系だけで、そこではマインドマップのほうが「置ける物のひとつ」へ
  格下げされている。キャンバスが主か木が主かで界隈は割れていて、中間は空白
- **Excalidraw / tldraw が刺さっている理由は機能の多さではない** — 開いて数秒で
  描き始められること、道具が少ないこと、見た目に意志があること
- **画像への注釈は別ジャンルとして確立している**（Skitch 系）。道具は判で押した
  ように矢印・四角・フリーハンドに収束していて、価値は「数秒で渡せる」こと
- **Obsidian + Excalidraw** が一番近い先例で、「テキストと同じ場所に住む、再編集
  できるスケッチ」は既に成立するパターンだと分かる

したがって draw は共同ボードの縮小版ではなく、**カードの中身をその場で作る近道**。
仕事は 2 つしかない:

| | 何か | 紙 |
|---|---|---|
| **A** | 白紙の走り書き。木に名前を付けられない考えの逃げ道 | 透明 |
| **B** | 貼ってある画像への注釈 | その画像 |

道具（ペン・消しゴム・色・太さ）はほぼ完全に一致するので、**窓は 1 つでよく、
違いは紙だけ**。入口の選択状態が紙を決めるので、モードの切り替えも要らない。

## いま決めていないこと

**draw を育てるか捨てるかは、使い込んでから決める。** 出番の無い機能に構造投資
するのが、いちばん高くつく無駄なので。

育てるなら:

- **A はインライン SVG で書く。** `<svg>…</svg>` ブロックは既にカードとして
  描画され、その場で編集もできる。文書の Undo に乗り、未保存でも描け、名前の
  入力も画像フォルダも要らない。開き直せるかどうかは**印を信じず、全要素を筆に
  戻せたかで決める**（型は名乗らせず確かめる、と同じ）。`strokes → svg → strokes`
  の往復テストで見張れる。代償は md が長くなること
- **B は焼き込んだ WebP を新しいファイルへ。** ラスタの上の注釈を SVG で持とうと
  すると、元画像を base64 で md に抱えるしかなく、そこが破綻点になる

捨てるなら `app/draw.ts` と `Shift+D` を落とし、貼り付け（`Mod+V` / ドロップ）に
一本化する。外の道具で描いて貼る道は残るので、機能が消えるわけではない。

いま在るのは WebP 一本の白紙スケッチだけで、その形には手を付けていない
（2026-08-27 に道具立ての並びと見た目だけを整えた）。
