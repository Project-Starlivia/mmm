# op — 木への操作 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `core/op` を足し、`apply(doc, op) -> Done?` で Doc を Doc にする 12 の操作を、手で組んだ木のテストで固定する。

**Architecture:** 表に出るのは `apply` と型（`NodePlace` / `BlockPlace` / `Op` / `Done`）だけ。読みの道具（`each` 1 本の歩きの上に `find` / `seat` / `owner` / `parent` / `pick` / `within` / `fresh` / `has`）と、書きの道具（`splice` / `append` / `body`）は private。型の異種性（3 種のノード・根だけの側・Implicit の存在条件）に触るのは `splice` / `append` / `body` の中だけで、Op は道具の組み合わせ。

**Tech Stack:** MoonBit（`moon 0.1.20260803`、target js）。テストは `*_wbtest.mbt`（private に触れる）。`@tree`（`core/tree`）の型と `parse` / `doc_id` / `Sign` を使う。

**Spec:** `docs/superpowers/specs/2026-09-04-op-design.md`

## Global Constraints

- **木は手で組む。`parse` で作らない**（Graft の入力 md を除く）。期待値も手で組んだ Doc で、`assert_eq` で比べる（Doc は `Eq` / `Debug` を導出済み。`side_wbtest.mbt` が同じ書き方）
- **`apply` の結果は `@tree.check` を通る。** 通らなければ操作のバグ
- 新しい id は文書に無い番号（最大 + 1）。既存の id は振り直さない
- 綴りの変換（見出し ⇄ 項目）はこの段に無い。見出しを項目の下へ落とすのは `None`
- コミットは `<Type>: <Emoji> <Title>` の日本語（例: `feat: ✨ 木を歩く道具を置く`）。末尾に `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`
- 作業は worktree `.worktrees/feat/op`（枝 `feat/op`、feat/tree から）
- **Windows:** moon を呼ぶ前に PATH を前置する（PowerShell: `$env:Path = "$env:USERPROFILE\.moon\bin;$env:Path"`）。`.mbt` の書き換えはシェルでなく Write / Edit ツールで（BOM と `\n` の罠）
- テストの実行: `cd core; moon test -p mmm-app/core/op`。整形: `cd core; moon fmt`。型検査: `cd core; moon check`
- **文中の全角括弧・句読点は既存ファイルに倣う**（コメントは日本語、`///|` で区切る）

```moonbit
// 木への操作。Doc を Doc にする純粋な関数の、入力の形。
//
// 席は隣の id で言い、添字は持たない（DOM の before / after / append と同じ形）。
// ノードの列と中身の列は交わらないので型を分け、同じ文法を使っていることは
// 型名が言う。構築子が位置を、ラベルが相手を言う。

///|
/// ノードの席。子の列の中。
pub(all) enum NodePlace {
  Before(node~ : Int)
  After(node~ : Int)
  /// 子の列の末尾。side は node が根のときだけ意味を持つ。
  /// node が doc_id なら新しい根
  In(node~ : Int, side~ : @tree.Side?)
} derive(Eq, Debug, ToJson)

///|
/// 中身の席。body の列の中。
pub(all) enum BlockPlace {
  Before(block~ : Int)
  After(block~ : Int)
  /// body の末尾。node が doc_id なら文書の散文
  In(node~ : Int)
} derive(Eq, Debug, ToJson)

///|
/// 操作。1 つの値が 1 回の操作で、apply が木に当てる。
pub(all) enum Op {
  Add(at~ : NodePlace, labels~ : Array[String])
  AddBlock(at~ : BlockPlace, content~ : @tree.Content)
  Rename(id~ : Int, label~ : String)
  SetBlock(id~ : Int, content~ : @tree.Content)
  Move(ids~ : Array[Int], at~ : NodePlace)
  MoveBlock(ids~ : Array[Int], at~ : BlockPlace)
  /// ノードも中身も。席を取らないので 1 つ
  Delete(ids~ : Array[Int])
  Wrap(id~ : Int, label~ : String)
  FlipSide(id~ : Int)
  Fold(id~ : Int, open~ : Bool)
  Unfold(id~ : Int)
  Graft(at~ : NodePlace, md~ : String)
} derive(Eq, Debug, ToJson)

///|
/// 操作後の木と、そこで選ぶべき id（消した後は None）。
pub(all) struct Done {
  doc : @tree.Doc
  focus : Int?
} derive(Eq, Debug, ToJson)
```

`core/op/walk.mbt`:

```moonbit
// 木を読むだけの道具。歩きは each 1 本で、seat / owner / pick / fresh はその上に乗る。
// 3 種のノードの違い（子の型・中身の有無）は id_of / kids / blocks_of で吸う。

///|
fn id_of(n : @tree.Node) -> Int {
  match n {
    HeadingNode(h) => h.id
    ListNode(l) => l.id
    ImplicitNode(g) => g.id
  }
}

///|
/// 子の列。項目の子は項目だが、歩くときは Node に包んで同じ列にする。
fn kids(n : @tree.Node) -> Array[@tree.Node] {
  match n {
    HeadingNode(h) => h.children
    ImplicitNode(g) => g.children
    ListNode(l) => l.children.map(c => @tree.ListNode(c))
  }
}

///|
/// 中身の列。Implicit は持たない。
fn blocks_of(n : @tree.Node) -> Array[@tree.Block] {
  match n {
    HeadingNode(h) => h.body
    ListNode(l) => l.body
    ImplicitNode(_) => []
  }
}

///|
/// 文書順に、ノードと中身を 1 つずつ訪ねる。f は (id, 中身か, 祖先の id 列) を
/// 受ける。祖先の列は歩きが使い回すので、f は持ち帰らない（要るなら copy）。
fn each(doc : @tree.Doc, f : (Int, Bool, Array[Int]) -> Unit) -> Unit {
  let path : Array[Int] = []
  fn node(n : @tree.Node) -> Unit {
    f(id_of(n), false, path)
    path.push(id_of(n))
    for b in blocks_of(n) {
      f(b.id, true, path)
    }
    for c in kids(n) {
      node(c)
    }
    ignore(path.pop())
  }

  for b in doc.body {
    f(b.id, true, path)
  }
  for r in doc.roots {
    node(r.node)
  }
}

///|
/// id のノード。中身の id には応えない。
fn find(doc : @tree.Doc, id : Int) -> @tree.Node? {
  fn go(n : @tree.Node) -> @tree.Node? {
    if id_of(n) == id {
      return Some(n)
    }
    for c in kids(n) {
      match go(c) {
        Some(m) => return Some(m)
        None => ()
      }
    }
    None
  }

  for r in doc.roots {
    match go(r.node) {
      Some(m) => return Some(m)
      None => ()
    }
  }
  None
}

///|
/// 根の添字から辿る道。長さが深さ（根 = 1、根の子 = 2）。中身には応えない。
fn seat(doc : @tree.Doc, id : Int) -> Array[Int]? {
  fn go(n : @tree.Node) -> Array[Int]? {
    if id_of(n) == id {
      return Some([])
    }
    for k, c in kids(n) {
      match go(c) {
        Some(p) => {
          p.insert(0, k)
          return Some(p)
        }
        None => ()
      }
    }
    None
  }

  for i, r in doc.roots {
    match go(r.node) {
      Some(p) => {
        p.insert(0, i)
        return Some(p)
      }
      None => ()
    }
  }
  None
}

///|
/// 祖先の列の末尾。無ければ doc_id（根と、文書の散文）。
fn above(path : Array[Int]) -> Int {
  match path.last() {
    Some(p) => p
    None => @tree.doc_id
  }
}

///|
/// その中身を body に持つノードの id。ノードの id には応えない。
fn owner(doc : @tree.Doc, block~ : Int) -> Int? {
  let found : Ref[Int?] = { val: None }
  each(doc, fn(id, is_block, path) {
    if is_block && id == block {
      found.val = Some(above(path))
    }
  })
  found.val
}

///|
/// 親の id。根なら doc_id、中身なら持ち主。
fn parent(doc : @tree.Doc, id : Int) -> Int? {
  let found : Ref[Int?] = { val: None }
  each(doc, fn(x, _, path) { if x == id { found.val = Some(above(path)) } })
  found.val
}

///|
/// 選んだ id を文書順に並べ、祖先が選ばれているものを落とす（親と一緒に動く）。
/// 知らない id は落ちる。
fn pick(doc : @tree.Doc, ids : Array[Int]) -> Array[Int] {
  let want : Set[Int] = Set::new()
  for id in ids {
    want.add(id)
  }
  let out = []
  each(doc, fn(id, _, path) {
    if want.contains(id) && !path.any(a => want.contains(a)) {
      out.push(id)
    }
  })
  out
}

///|
/// id か、その祖先が ids に居るか。動かすものの中へ落とすのを止める。
fn within(doc : @tree.Doc, id : Int, ids : Array[Int]) -> Bool {
  let hit : Ref[Bool] = { val: false }
  each(doc, fn(x, _, path) {
    if x == id && (ids.contains(x) || path.any(a => ids.contains(a))) {
      hit.val = true
    }
  })
  hit.val
}

///|
/// 文書に無い id。最大 + 1。空の文書なら doc_id + 1。
fn fresh(doc : @tree.Doc) -> Int {
  let top : Ref[Int] = { val: @tree.doc_id }
  each(doc, fn(id, _, _) { if id > top.val { top.val = id } })
  top.val + 1
}

///|
/// ノードでも中身でも、その id が在るか。
fn has(doc : @tree.Doc, id : Int) -> Bool {
  let hit : Ref[Bool] = { val: false }
  each(doc, fn(x, _, _) { if x == id { hit.val = true } })
  hit.val
}
```

- **型** — 親が項目なのに返された列に項目でないものがあれば `None`
- **sides** — 席が根の子なら、その側を返された数だけ複製。席が根そのものなら、id と子の数が同じものは元の sides、それ以外は `Right × 子の数`
- **Implicit の掃除** — 子が尽きた Implicit は空として親へ返す（根まで登れば Root ごと消える）

```moonbit
// 書きの道具。id の席を f の返した列に置き換え、根までの道を組み直す。
//
// **check の書き込み版。** 読む側で check が見張る 3 つの約束（項目の子は項目 /
// Implicit は子を持つ / sides は根の子と並走）を、書く側で破らないように組む
// 唯一の場所。f は「どうしたいか」だけを言い、できるかは席を知るここが決める。

///|
/// 1 回の置き換え。歩きながら「席が見つかったか」「席の型に合わなかったか」を残す。
priv struct Splice {
  id : Int
  f : (@tree.Node) -> Array[@tree.Node]
  mut hit : Bool
  mut bad : Bool
}

///|
/// id の席を f の返した列に置き換える。0 = 抜く、1 = 替える、n = 差す。
/// None は 2 つ: id が無い / 席の型に返された列が合わない（項目の下に見出し）。
fn splice(
  doc : @tree.Doc,
  id : Int,
  f : (@tree.Node) -> Array[@tree.Node],
) -> @tree.Doc? {
  let s : Splice = { id, f, hit: false, bad: false }
  let roots : Array[@tree.Root] = []
  for r in doc.roots {
    if id_of(r.node) == id {
      s.hit = true
      for y in f(r.node) {
        roots.push({ node: y, sides: sides_for(y, r) })
      }
    } else {
      match reroot(s, r) {
        Some(x) => roots.push(x)
        None => ()
      }
    }
  }
  if !s.hit || s.bad {
    None
  } else {
    Some({ ..doc, roots })
  }
}

///|
/// 根の席に置くものの sides。id も子の数も同じなら元のまま、それ以外は Right × 子の数
/// （新しい根は右から始まる。包んだ根が `[Right]` になるのもこの規則）。
fn sides_for(y : @tree.Node, old : @tree.Root) -> Array[@tree.Side] {
  let n = kids(y).length()
  if id_of(y) == id_of(old.node) && n == old.sides.length() {
    old.sides
  } else {
    Array::make(n, @tree.Right)
  }
}

///|
/// 根 1 本。子の列と sides を並走して組み直す。Implicit の子が尽きたら None。
fn reroot(s : Splice, r : @tree.Root) -> @tree.Root? {
  match r.node {
    HeadingNode(h) => {
      let (children, sides) = wing(s, h.children, r.sides)
      Some({ node: HeadingNode({ ..h, children }), sides })
    }
    ImplicitNode(g) => {
      let (children, sides) = wing(s, g.children, r.sides)
      if children.is_empty() {
        None
      } else {
        Some({ node: ImplicitNode({ ..g, children }), sides })
      }
    }
    ListNode(l) => {
      let (children, sides) = wing_items(s, l.children, r.sides)
      Some({ node: ListNode({ ..l, children }), sides })
    }
  }
}

///|
/// 根の子の列。席なら、その側を返された数だけ複製する。
fn wing(
  s : Splice,
  xs : Array[@tree.Node],
  sides : Array[@tree.Side],
) -> (Array[@tree.Node], Array[@tree.Side]) {
  let out = []
  let out_sides = []
  for i, x in xs {
    let side = if i < sides.length() { sides[i] } else { @tree.Right }
    if id_of(x) == s.id {
      s.hit = true
      for y in (s.f)(x) {
        out.push(y)
        out_sides.push(side)
      }
    } else {
      match rebuild(s, x) {
        Some(y) => {
          out.push(y)
          out_sides.push(side)
        }
        None => ()
      }
    }
  }
  (out, out_sides)
}

///|
/// 項目が根のときの子の列。
fn wing_items(
  s : Splice,
  xs : Array[@tree.ListNode],
  sides : Array[@tree.Side],
) -> (Array[@tree.ListNode], Array[@tree.Side]) {
  let out = []
  let out_sides = []
  for i, x in xs {
    let side = if i < sides.length() { sides[i] } else { @tree.Right }
    if x.id == s.id {
      s.hit = true
      for y in (s.f)(@tree.ListNode(x)) {
        match y {
          ListNode(l) => {
            out.push(l)
            out_sides.push(side)
          }
          _ => s.bad = true
        }
      }
    } else {
      out.push(relist(s, x))
      out_sides.push(side)
    }
  }
  (out, out_sides)
}

///|
/// ノード 1 つ。子の列を組み直し、Implicit の子が尽きたら None。
fn rebuild(s : Splice, x : @tree.Node) -> @tree.Node? {
  match x {
    HeadingNode(h) => Some(HeadingNode({ ..h, children: nodes(s, h.children) }))
    ListNode(l) => Some(ListNode(relist(s, l)))
    ImplicitNode(g) => {
      let children = nodes(s, g.children)
      if children.is_empty() {
        None
      } else {
        Some(ImplicitNode({ ..g, children }))
      }
    }
  }
}

///|
/// 見出し・Implicit の子の列。何でも来る。
fn nodes(s : Splice, xs : Array[@tree.Node]) -> Array[@tree.Node] {
  let out = []
  for x in xs {
    if id_of(x) == s.id {
      s.hit = true
      for y in (s.f)(x) {
        out.push(y)
      }
    } else {
      match rebuild(s, x) {
        Some(y) => out.push(y)
        None => ()
      }
    }
  }
  out
}

///|
fn relist(s : Splice, l : @tree.ListNode) -> @tree.ListNode {
  { ..l, children: items(s, l.children) }
}

///|
/// 項目の子の列。項目しか置けない（型が強いる）。
fn items(s : Splice, xs : Array[@tree.ListNode]) -> Array[@tree.ListNode] {
  let out = []
  for x in xs {
    if x.id == s.id {
      s.hit = true
      for y in (s.f)(@tree.ListNode(x)) {
        match y {
          ListNode(l) => out.push(l)
          _ => s.bad = true
        }
      }
    } else {
      out.push(relist(s, x))
    }
  }
  out
}
```

```moonbit
///|
/// 子の列に足したノード。項目の下に項目でないものは置けない。
fn with_kids(n : @tree.Node, more : Array[@tree.Node]) -> @tree.Node? {
  match n {
    HeadingNode(h) => Some(HeadingNode({ ..h, children: [..h.children, ..more] }))
    ImplicitNode(g) => Some(ImplicitNode({ ..g, children: [..g.children, ..more] }))
    ListNode(l) => {
      let children = l.children.copy()
      for y in more {
        match y {
          ListNode(c) => children.push(c)
          _ => return None
        }
      }
      Some(ListNode({ ..l, children }))
    }
  }
}

///|
/// In の席。隣が居ないので f でなく列を受け取り、子の列の末尾に足す。
/// node が根なら sides も足す — side があればそれ、無ければ末尾の子の側、
/// 子が無ければ Right。node が doc_id なら新しい根（sides は Right × 子の数）。
fn append(
  doc : @tree.Doc,
  node~ : Int,
  side? : @tree.Side,
  nodes : Array[@tree.Node],
) -> @tree.Doc? {
  if node == @tree.doc_id {
    let roots = doc.roots.copy()
    for y in nodes {
      roots.push({ node: y, sides: Array::make(kids(y).length(), @tree.Right) })
    }
    return Some({ ..doc, roots })
  }
  for i, r in doc.roots {
    if id_of(r.node) == node {
      guard with_kids(r.node, nodes) is Some(n) else { return None }
      let s = match side {
        Some(s) => s
        None =>
          match r.sides.last() {
            Some(s) => s
            None => @tree.Right
          }
      }
      let sides = r.sides.copy()
      for _ in nodes {
        sides.push(s)
      }
      let roots = doc.roots.copy()
      roots[i] = { node: n, sides }
      return Some({ ..doc, roots })
    }
  }
  guard find(doc, node) is Some(n) else { return None }
  guard with_kids(n, nodes) is Some(m) else { return None }
  splice(doc, node, _ => [m])
}

///|
/// 中身の列を直す。node が doc_id なら文書の散文。Implicit は中身を持たないので None。
fn body(
  doc : @tree.Doc,
  node~ : Int,
  f : (Array[@tree.Block]) -> Array[@tree.Block],
) -> @tree.Doc? {
  if node == @tree.doc_id {
    return Some({ ..doc, body: f(doc.body) })
  }
  guard find(doc, node) is Some(n) else { return None }
  let m = match n {
    HeadingNode(h) => @tree.HeadingNode({ ..h, body: f(h.body) })
    ListNode(l) => @tree.ListNode({ ..l, body: f(l.body) })
    ImplicitNode(_) => return None
  }
  splice(doc, node, _ => [m])
}
```

```moonbit
// 操作を木に当てる。Op は道具の組み合わせで、型の異種性には触らない。
//
// None は「できない操作」。ts は spec どおり押す前に沈めるので、core は静かに断る。
// 途中で失敗しても元の doc は変わらない（道具が純粋なので）。

///|
pub fn apply(doc : @tree.Doc, op : Op) -> Done? {
  match op {
    Rename(id~, label~) => rename(doc, id, label)
    Fold(id~, open~) => fold(doc, id, open)
    Unfold(id~) => unfold(doc, id)
    Delete(ids~) => delete(doc, ids)
    Add(at~, labels~) => add(doc, at, labels)
    Wrap(id~, label~) => wrap(doc, id, label)
    Move(ids~, at~) => move(doc, ids, at)
    FlipSide(id~) => flip(doc, id)
    AddBlock(at~, content~) => add_block(doc, at, content)
    SetBlock(id~, content~) => set_block(doc, id, content)
    MoveBlock(ids~, at~) => move_block(doc, ids, at)
    Graft(at~, md~) => graft(doc, at, md)
  }
}

///|
/// 道具の結果を Done に包む。
fn done(doc : @tree.Doc?, focus : Int?) -> Done? {
  match doc {
    Some(d) => Some({ doc: d, focus })
    None => None
  }
}

///|
/// ラベルを替える。Implicit は見出しとして綴られる。
fn rename(doc : @tree.Doc, id : Int, label : String) -> Done? {
  guard find(doc, id) is Some(n) else { return None }
  let m = match n {
    HeadingNode(h) => @tree.HeadingNode({ ..h, label })
    ListNode(l) => @tree.ListNode({ ..l, label })
    ImplicitNode(g) =>
      @tree.HeadingNode({ id: g.id, label, fold: None, body: [], children: g.children })
  }
  done(splice(doc, id, _ => [m]), Some(id))
}

///|
/// 定義ごと畳む。名前はラベル（書けなければ名無し）。畳み済みなら open だけ替わる。
fn fold(doc : @tree.Doc, id : Int, open : Bool) -> Done? {
  guard find(doc, id) is Some(n) else { return None }
  fn folding(label : String) -> @tree.Fold {
    { open, summary: if @tree.writable(label) { Some(label) } else { None } }
  }

  let m = match n {
    HeadingNode(h) => @tree.HeadingNode({ ..h, fold: Some(folding(h.label)) })
    ListNode(l) => @tree.ListNode({ ..l, fold: Some(folding(l.label)) })
    ImplicitNode(_) => return None
  }
  done(splice(doc, id, _ => [m]), Some(id))
}

///|
/// 畳みを外す。中身はその場で普通の md として読み直される（読みのサイクルの仕事）。
fn unfold(doc : @tree.Doc, id : Int) -> Done? {
  guard find(doc, id) is Some(n) else { return None }
  let m = match n {
    HeadingNode(h) => {
      guard h.fold is Some(_) else { return None }
      @tree.HeadingNode({ ..h, fold: None })
    }
    ListNode(l) => {
      guard l.fold is Some(_) else { return None }
      @tree.ListNode({ ..l, fold: None })
    }
    ImplicitNode(_) => return None
  }
  done(splice(doc, id, _ => [m]), Some(id))
}

///|
/// 1 つ消す。ノードは部分木ごと、中身は 1 枚。
fn erase(doc : @tree.Doc, id : Int) -> @tree.Doc? {
  match owner(doc, block=id) {
    Some(o) => body(doc, node=o, bs => bs.filter(b => b.id != id))
    None => splice(doc, id, _ => [])
  }
}

///|
/// 選んだものを文書順に消す。知らない id が 1 つでもあれば None。
fn delete(doc : @tree.Doc, ids : Array[Int]) -> Done? {
  guard !ids.is_empty() && ids.all(id => has(doc, id)) else { return None }
  let mut cur = doc
  for id in pick(doc, ids) {
    guard erase(cur, id) is Some(d) else { return None }
    cur = d
  }
  Some({ doc: cur, focus: None })
}
```

`Array::all` が無ければ（`moon check` が言う）`for` で書く:

```moonbit
  for id in ids {
    guard has(doc, id) else { return None }
  }
```

```moonbit
///|
/// その綴りで空のノードを作る。
fn make(sign : @tree.Sign, id : Int, label : String) -> @tree.Node {
  match sign {
    Heading => @tree.HeadingNode({ id, label, fold: None, body: [], children: [] })
    Item => @tree.ListNode({ id, label, fold: None, body: [], children: [] })
  }
}

///|
fn sign_of(n : @tree.Node) -> @tree.Sign {
  match n {
    ListNode(_) => Item
    _ => Heading
  }
}

///|
/// この下に足すときの綴り。末尾の子がいればそれに、いなければ親に従う
/// （項目の下は項目、それ以外は見出し）。
fn sign_in(n : @tree.Node) -> @tree.Sign {
  match kids(n).last() {
    Some(c) => sign_of(c)
    None => sign_of(n)
  }
}

///|
/// 席が指している id。
fn anchor(at : NodePlace) -> Int {
  match at {
    Before(node~) => node
    After(node~) => node
    In(node~, ..) => node
  }
}

///|
/// 新しいノードを差す。綴りは隣に従う。
fn add(doc : @tree.Doc, at : NodePlace, labels : Array[String]) -> Done? {
  guard !labels.is_empty() else { return None }
  let first = fresh(doc)
  fn news(sign : @tree.Sign) -> Array[@tree.Node] {
    labels.mapi((k, label) => make(sign, first + k, label))
  }

  let out = match at {
    Before(node~) => {
      guard find(doc, node) is Some(n) else { return None }
      splice(doc, node, x => [..news(sign_of(n)), x])
    }
    After(node~) => {
      guard find(doc, node) is Some(n) else { return None }
      splice(doc, node, x => [x, ..news(sign_of(n))])
    }
    In(node~, side~) => {
      let sign = if node == @tree.doc_id {
        Heading
      } else {
        guard find(doc, node) is Some(n) else { return None }
        sign_in(n)
      }
      append(doc, node~, side?, news(sign))
    }
  }
  done(out, Some(first))
}

///|
/// 新しいノードが id の席に座り、id はその唯一の子になる。綴りは id と同じ。
fn wrap(doc : @tree.Doc, id : Int, label : String) -> Done? {
  guard find(doc, id) is Some(n) else { return None }
  let nid = fresh(doc)
  let w = match n {
    ListNode(l) => @tree.ListNode({ id: nid, label, fold: None, body: [], children: [l] })
    _ => @tree.HeadingNode({ id: nid, label, fold: None, body: [], children: [n] })
  }
  done(splice(doc, id, _ => [w]), Some(nid))
}
```

```moonbit
///|
/// 文書順に抜き取る。抜いたものは taken に、残りの木を返す。
fn take(doc : @tree.Doc, ids : Array[Int], taken : Array[@tree.Node]) -> @tree.Doc? {
  let mut cur = doc
  for id in ids {
    let pulled = splice(cur, id, fn(n) {
      taken.push(n)
      []
    })
    match pulled {
      Some(d) => cur = d
      None => return None
    }
  }
  Some(cur)
}

///|
/// 席に差す。
fn place(doc : @tree.Doc, at : NodePlace, nodes : Array[@tree.Node]) -> @tree.Doc? {
  match at {
    Before(node~) => splice(doc, node, x => [..nodes, x])
    After(node~) => splice(doc, node, x => [x, ..nodes])
    In(node~, side~) => append(doc, node~, side?, nodes)
  }
}

///|
/// 動かす。文書順を保って抜き、席に差す。側は行き先が決め、綴りは保つ。
fn move(doc : @tree.Doc, ids : Array[Int], at : NodePlace) -> Done? {
  guard !ids.is_empty() else { return None }
  for id in ids {
    guard find(doc, id) is Some(_) else { return None }
  }
  let picked = pick(doc, ids)
  guard !within(doc, anchor(at), picked) else { return None }
  let taken = []
  guard take(doc, picked, taken) is Some(rest) else { return None }
  done(place(rest, at, taken), Some(picked[0]))
}

///|
fn flipped(s : @tree.Side) -> @tree.Side {
  match s {
    Right => Left
    Left => Right
  }
}

///|
/// 側を裏返す。根は sides を一括反転（鏡像）、根の子はその 1 つ、深いノードは
/// 反対側の末尾へ引き出す（深さは保つので、間を Implicit が埋める）。
fn flip(doc : @tree.Doc, id : Int) -> Done? {
  guard seat(doc, id) is Some(path) else { return None }
  let roots = doc.roots.copy()
  let r = roots[path[0]]
  fn side_at(j : Int) -> @tree.Side {
    if j < r.sides.length() {
      r.sides[j]
    } else {
      @tree.Right
    }
  }

  match path.length() {
    1 => {
      roots[path[0]] = { ..r, sides: r.sides.map(flipped) }
      Some({ doc: { ..doc, roots }, focus: Some(id) })
    }
    2 => {
      let sides = r.sides.copy()
      sides[path[1]] = flipped(side_at(path[1]))
      roots[path[0]] = { ..r, sides }
      Some({ doc: { ..doc, roots }, focus: Some(id) })
    }
    depth => {
      let side = flipped(side_at(path[1]))
      let mut next = fresh(doc)
      let taken = []
      guard take(doc, [id], taken) is Some(rest) else { return None }
      let mut wrapped = taken[0]
      for _ in 0..<(depth - 2) {
        wrapped = @tree.ImplicitNode({ id: next, children: [wrapped] })
        next = next + 1
      }
      done(append(rest, node=id_of(r.node), side~, [wrapped]), Some(id))
    }
  }
}
```

```moonbit
///|
/// 中身の列の中に差す。Before / After は隣の id で、In は末尾。
fn put(
  bs : Array[@tree.Block],
  at : BlockPlace,
  more : Array[@tree.Block],
) -> Array[@tree.Block] {
  match at {
    In(..) => [..bs, ..more]
    Before(block~) => {
      let out = []
      for b in bs {
        if b.id == block {
          out.push_iter(more.iter())
        }
        out.push(b)
      }
      out
    }
    After(block~) => {
      let out = []
      for b in bs {
        out.push(b)
        if b.id == block {
          out.push_iter(more.iter())
        }
      }
      out
    }
  }
}

///|
/// 席の持ち主。Before / After は隣の持ち主、In はそのノード。
fn holder(doc : @tree.Doc, at : BlockPlace) -> Int? {
  match at {
    Before(block~) => owner(doc, block~)
    After(block~) => owner(doc, block~)
    In(node~) => Some(node)
  }
}

///|
fn add_block(doc : @tree.Doc, at : BlockPlace, content : @tree.Content) -> Done? {
  guard holder(doc, at) is Some(o) else { return None }
  let b : @tree.Block = { id: fresh(doc), content }
  done(body(doc, node=o, bs => put(bs, at, [b])), Some(b.id))
}

///|
fn set_block(doc : @tree.Doc, id : Int, content : @tree.Content) -> Done? {
  guard owner(doc, block=id) is Some(o) else { return None }
  done(
    body(doc, node=o, bs => bs.map(b => if b.id == id { { id, content } } else { b })),
    Some(id),
  )
}

///|
/// 中身を動かす。文書順を保って持ち主ごとに抜き、席に差す。
fn move_block(doc : @tree.Doc, ids : Array[Int], at : BlockPlace) -> Done? {
  guard !ids.is_empty() else { return None }
  for id in ids {
    guard owner(doc, block=id) is Some(_) else { return None }
  }
  let picked = pick(doc, ids)
  guard !picked.contains(anchor_block(at)) else { return None }
  let taken = []
  let mut cur = doc
  for id in picked {
    guard owner(cur, block=id) is Some(o) else { return None }
    let pulled = body(cur, node=o, fn(bs) {
      let out = []
      for b in bs {
        if b.id == id {
          taken.push(b)
        } else {
          out.push(b)
        }
      }
      out
    })
    match pulled {
      Some(d) => cur = d
      None => return None
    }
  }
  guard holder(cur, at) is Some(o) else { return None }
  done(body(cur, node=o, bs => put(bs, at, taken)), Some(picked[0]))
}

///|
/// 席が指している id。
fn anchor_block(at : BlockPlace) -> Int {
  match at {
    Before(block~) => block
    After(block~) => block
    In(node~) => node
  }
}
```

```moonbit
///|
/// 部分木の id をまとめてずらす。parse が振った番号を、いまの木に無い番号へ。
fn shift(n : @tree.Node, by : Int) -> @tree.Node {
  fn blocks(bs : Array[@tree.Block]) -> Array[@tree.Block] {
    bs.map(b => { id: b.id + by, content: b.content })
  }

  fn list(l : @tree.ListNode) -> @tree.ListNode {
    { ..l, id: l.id + by, body: blocks(l.body), children: l.children.map(list) }
  }

  match n {
    HeadingNode(h) =>
      @tree.HeadingNode({
        ..h,
        id: h.id + by,
        body: blocks(h.body),
        children: h.children.map(c => shift(c, by)),
      })
    ListNode(l) => @tree.ListNode(list(l))
    ImplicitNode(g) =>
      @tree.ImplicitNode({ id: g.id + by, children: g.children.map(c => shift(c, by)) })
  }
}

///|
/// md を読んで、根たちを席に差す。側は捨て、綴りは読んだまま。
/// 先頭の散文は行き先の親の body 末尾へ（In なら node 自身、根の間なら doc の散文）。
fn graft(doc : @tree.Doc, at : NodePlace, md : String) -> Done? {
  let sub = @tree.parse(md)
  guard !(sub.roots.is_empty() && sub.body.is_empty()) else { return None }
  let by = fresh(doc) - (@tree.doc_id + 1)
  let prose = sub.body.map(b => ({ id: b.id + by, content: b.content } : @tree.Block))
  let subs = sub.roots.map(r => shift(r.node, by))
  let host = match at {
    In(node~, ..) => node
    _ => {
      guard parent(doc, anchor(at)) is Some(p) else { return None }
      p
    }
  }
  guard has(doc, anchor(at)) || anchor(at) == @tree.doc_id else { return None }
  let mut cur = doc
  if !prose.is_empty() {
    guard body(cur, node=host, bs => [..bs, ..prose]) is Some(d) else { return None }
    cur = d
  }
  if subs.is_empty() {
    return Some({ doc: cur, focus: None })
  }
  done(place(cur, at, subs), Some(id_of(subs[0])))
}
```

```
文書の散文。側は `NodePlace::In` だけが持つ。

### 決め

- **側は根のもの。** 枝を動かしても側は運ばれず、行き先が決め直す。`Before` /
  `After` は隣の側、`In(根, side)` は `Some` ならそれ、`None` なら末尾の子の側、
  子が無ければ Right
- **新しいノードの綴りは隣に従う。** 兄弟がいればその sign、いなければ親が項目なら
  項目、それ以外は見出し。モードは Reform と一緒に来る
- **動かすノードは綴りを保つ。** 綴りの変換（見出し ⇄ 項目）は正規形の仕事で、
  操作には無い。見出しを項目の下へ落とすのは型が許さないので `None`
- **flipSide は 3 段。** 根は `sides` を一括反転(鏡像)、根の子はその 1 つを反転、
  深いノードは反対側の末尾へ引き出す(深さは保つので、間を Implicit が埋める)
- **選んだ祖先の中の子孫は無視する。** `Delete` / `Move` の ids に親と子が両方
  あれば、子は親と一緒に動く。基準の id が動かすものの中なら `None`
- **Implicit は子が尽きたら消える。** 根まで登れば Root ごと
- **Implicit に名を付ければ見出しになる。** 畳みの名前はラベル（`<summary>` に
  書けなければ名無しで畳む）。Implicit は畳めない
- **比例性** — 操作の影響は、選んだ部分木とその親の中に収まる
- **文字列は常に md として解釈される。** ラベル専用のエスケープや拒否は作らない
- **apply の結果は check を通る。** 通らなければ操作のバグ
- 新しい id は文書に無い番号（最大 + 1）。既存の id は振り直さない（反映が前後を
  id の等しさで突き合わせる）。undo は core に無い — 反映が純粋関数なので
  CodeMirror のもの
```
