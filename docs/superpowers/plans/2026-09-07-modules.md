# modules — 実装の段取り

決めは [2026-09-07-modules-design.md](../specs/2026-09-07-modules-design.md)。各段は 1 PR、main に squash。

## 段 1: core を 2 module に

- [ ] `core/` に tree / op / read / map だけ残す。`view/` は `tree/view.mbt`、`edit/` は `op/edit.mbt`
- [ ] `app/`（module `mmm/app`）に web / parts / render / app / file / main / js を移す。`moon.mod` は core を path で import
- [ ] package.json の `core` / `check:core` / `test:core` を両 module に。core の moon.pkg に `mizchi/*` / `moonbitlang/async` が無いことを見る
- [ ] vite / src / lab の import の道を `app/_build/js/release/build/js/js.js` に
- [ ] docs/spec.md・docs/core.md の一覧

## 段 2: app の科

- [ ] `bar/` — files / more / export / theme(+logo) / name（app.mbt から名乗りと未保存の印を切り出す）
- [ ] `disk/` — io / handles / assets / dnd（改名は段 3）
- [ ] `mindmap/` — render/ を改名し、mindmap.mbt を mindmap / input / act / marks に割る。export.mbt → svg.mbt
- [ ] `parts/` に ask / asks / draw
- [ ] root — app / panes / persist / shortcuts / share を平らに。`main/` は無くなる
- [ ] docs
