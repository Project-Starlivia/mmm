## Global Constraints

- **命名は CLAUDE.md。** 判断の関数は今の TS の名のまま移す（意味を変えない移送）。コミットは `<Type>: <Emoji> #143 <Title>`。
- **境界は数・文字列・真偽・持ち手・小さな JSON。** 木と箱を渡す出口を新しく作らない。
- **段ごとに wbtest を付けてからコミット。** TS の試験は同じ内容の wbtest に移し、TS 側は消す。
- 作業場所は `.worktrees/feat/mbt`（枝 `feat/mbt`、main から）。段ごとに枝を切って PR を feat/mbt に向ける。`.mbt` は Write / Edit ツールで。**bash の文字列にバッククォートを入れない。**
- コミット末尾に `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`。
