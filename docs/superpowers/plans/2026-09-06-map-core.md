# map-core — map を core で置き、描く 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `src/map` の純粋な半分と SVG の半分を MoonBit の core（`core/map` / `core/render`）へ移し、TS は入力・視点・書き出し・字の実測・色分けだけを持つ。DOM の契約（class / data-*）は変えず、見た目も変えない。

**Architecture:** [docs/superpowers/specs/2026-09-06-map-core-design.md](../specs/2026-09-06-map-core-design.md)

**Tech Stack:** MoonBit 0.10.11（`mizchi/js_browser@0.12.2`）、TypeScript strict、node:test、happy-dom。

**Issue:** #137

## Global Constraints

- **命名は CLAUDE.md。** 最もシンプルかつジェネリックな名で。コミットは `<Type>: <Emoji> #137 <Title>`（日本語）。
- **core の語は読むだけ。** `@view.Node` / `@view.Root` / `@tree.Side` / `@tree.Block` を言い換えない。
- **寸法の数字は `core/map/metric.mbt` にしか書かない。** TS に残る数は当たりの広げ幅（`select.ts` の `GRAB`）と入力欄の枠・余白だけ。
- **DOM の契約を変えない。** class 名・`data-*`・要素の並びは今の `render.ts` / `drawCard.ts` と同じ。style.css に触らない。
- **段ごとに単体テストを付けてからコミット。** 段 2・3 は `moon test`、段 4 は happy-dom、結合（ブラウザ）は段 5。
- 作業場所は `.worktrees/feat/map-core`（枝 `feat/map-core`、main から）。段ごとに枝を切って PR を feat/map-core に向ける。Windows では `moon` の PATH 前置が要る。`.mbt` の書き換えは Write / Edit ツールで（シェル経由は BOM と `\` で壊す）。
