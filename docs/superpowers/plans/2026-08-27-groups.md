# `---` の分割（グループと左右）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `---` 1 本でルート直下の枝をグループに分け、`---` 2 本でそこから先を
ルートの反対側（左）へ振り分ける。読み・表示・操作・掃除まで。

**Architecture:** 「どの行が区切りか」「どのグループのどちら側か」は **core が
唯一の判定者**で、スナップショットの各ノードに `group` / `left` として載る。TS は
それを**見せ方**（左右ミラー・グループ間の余白・継ぎ目の線・ドロップ）に使うだけで、
区切りの規則を書き直さない。書く側（境界の追加・書き直し・掃除）も core の
`core/seps.mbt` 1 か所に置く — 読みと書きが離れていると、片方だけ直したときに
静かに食い違う。

**Tech Stack:** MoonBit（`core/`、`moon test`）/ TypeScript + Vite（`src/`）/
`node --test`（`test/`）

**Spec:** [docs/superpowers/specs/2026-08-27-groups-design.md](../specs/2026-08-27-groups-design.md)

## Global Constraints

- **画面に出る文字は英語**（ボタン・メニュー・通知）。docs とコード内のコメントは日本語
- **`as T` と `!` を書かない**。`instanceof` / 型ガード / 既定値で確かめる
  （`test/assertions.test.ts` が見張る）
- **改行は常に LF**（core の `eol`）
- **コミットは Semantic Commit Message**: `<Type>: <Emoji> <Title>`（日本語の Title）
- **各タスクの最後に必ず 3 つとも通す**: `pnpm run test:core` / `pnpm test` / `pnpm run check`
- **`git stash` を使わない**（ワークツリー共用のため。CLAUDE.md）
- 深さの読み替えはしない。`Node.depth` は書かれた深さのまま（v1 の raw_depth 分裂の再演を避ける）
- 区切りの綴りは `---` / `***` / `___`（同じ印が 3 つ以上連続する形だけ）。
  **道具が書くのは常に `---`**

```moonbit
/// 区切り行（thematic break）の**連続したかたまり** = 1 つの境界の候補。
```

```moonbit
///|
/// thematic break の行なら、その印の文字コード（`-` = 45 / `*` = 42 / `_` = 95）。
/// 違えば 0。
///
/// **同じ印が 3 つ以上続く形だけ**を見る。`- - -` のように間を空けた形は
/// CommonMark では同じ thematic break だが、mmm の読みでは前からリスト項目
/// （`-` + 空白）なので、そちらの読みを変えないためにここでは拾わない。
/// 道具が書くのは常に `---` の形なので、書き手側で困ることは無い。
///
/// 行頭の空白は **`base` 列からさらに 3 つまで**。`base` は囲っているリスト
/// 項目の中身の列で、フェンス（`fence_open`）と同じ数え方 — リストの形の
/// 文書では、区切りもその列に書かれるため。
fn thematic_break_at(text : String, l : Line, base : Int) -> Int {
  let mut p = l.start
  let mut indent = 0
  while p < l.end && is_space(code_at(text, p)) && indent < base + 3 {
    indent = indent + (if code_at(text, p) == 9 { 2 } else { 1 })
    p = p + 1
  }
  // base+3 を越えて空白が続く = 外のパーサではコードブロック
  if p >= l.end || is_space(code_at(text, p)) {
    return 0
  }
  let c = code_at(text, p)
  if c != 45 && c != 42 && c != 95 {
    return 0
  }
  let (a, b) = trim_range(text, p, l.end)
  if b - a < 3 {
    return 0
  }
  for q = a; q < b; q = q + 1 {
    if code_at(text, q) != c {
      return 0
    }
  }
  c
}
```

```moonbit
// `---` の境界と、グループ・左右。
//
// **どの区切り行が構造として効くかを決めるのはここだけ。** 行の並び（連続した
// かたまり）はパーサが数え、木の形を見た有効性の判定と、グループ番号・左右の
// 割り当てをここが持つ。
//
// 記法: `---` 1 本 = 分割（同じ側に次のグループ）、2 本以上 = 分割 + 切り替え
// （そこから先は反対側）。本数の偶奇に意味を持たせないのは、手で 1 本足した
// だけで遠くの表示が変わる形を避けるため。

///|
/// 有効な境界 1 つ。`flip` なら、ここから先のグループは反対側へ伸びる。
priv struct Bound {
  start : Int // かたまりの最初の区切り行の行頭
  end : Int // 最後の区切り行の次の行頭
  flip : Bool // 区切り行が 2 本以上
}

///|
/// 区切りのかたまりのうち、**構造として効くもの**だけ。
///
/// 有効なのは「直前にノード P があり、直後の最初のノード F が P の木のルートの
/// 直下」であるとき。この 1 つの判定だけで
///   - front matter の `---`（P が無い）
///   - 木をまたぐ `---`（F が別の木のルート = 親なし）
///   - 深い階層の `---`（F の親がルートでない）
/// が、特別扱い無しに全部落ちる。
fn valid_bounds(
  seps : Array[SepRun],
  heads : Array[Heading],
  pidx : Array[Int],
) -> Array[Bound] {
  let out : Array[Bound] = []
  let hn = heads.length()
  let mut k = 0
  for r in seps {
    // k = そのかたまりより後ろの最初のノード。区切りもノードも文書順なので
    // 巻き戻らない（両方を 1 度ずつ歩けば足りる）
    while k < hn && heads[k].from < r.start {
      k = k + 1
    }
    if k == 0 || k >= hn {
      continue
    }
    let mut root = k - 1
    while pidx[root] >= 0 {
      root = pidx[root]
    }
    if pidx[k] != root {
      continue
    }
    out.push(Bound::{ start: r.start, end: r.end, flip: r.lines >= 2 })
  }
  out
}

///|
/// 境界で範囲を切る。**切るのは「その境界の直前で終わるノード」だけ** —
/// 一律に切ると、子を全部含むはずのルートの範囲まで切れて、境界の後ろの
/// グループがルートの子でなくなる（v1 で実際に踏んだ）。
///
/// 切る相手は、境界の直後のノード F の行頭でちょうど終わっているノード。
/// 後ろから辿り、境界を越えて伸びるノード（ルート）に当たったら止める。
fn cut_ranges(
  bounds : Array[Bound],
  heads : Array[Heading],
  range_end : Array[Int],
) -> Unit {
  let hn = heads.length()
  let mut k = 0
  for b in bounds {
    while k < hn && heads[k].from < b.start {
      k = k + 1
    }
    if k >= hn {
      continue
    }
    let f = heads[k].from
    for i = k - 1; i >= 0; i = i - 1 {
      if range_end[i] > f {
        break // 境界を越えて伸びる = この境界で終わっていない
      }
      if range_end[i] == f {
        range_end[i] = b.start
      }
    }

///|

///
/// **グループはルート直下の話**だが、値は枝の中の全ノードに配る — UI が
/// 「この枝はどっち側か」を導き直さなくていいように（同じ規則が 2 か所に
/// あると、片方だけ直したときに静かに食い違う）。
fn assign_groups(bounds : Array[Bound]) -> Unit {
  let mut bi = 0
  let mut group = 0
  let mut left = false
  for i = 0; i < st.nodes.length(); i = i + 1 {
    let nd = st.nodes[i]
    while bi < bounds.length() && bounds[bi].start < nd.from {
      group = group + 1
      if bounds[bi].flip {
        left = !left
      }
      bi = bi + 1
    }
    if nd.parent == -1 {
      // 新しい木。番号も側も振り出しに戻る（各木が自分の区切りを読む）
      group = 0
      left = false
    }
    nd.group = group
    nd.left = left
  }
}
```

```moonbit
/// 深さと範囲から「親の添字」を出す（-1 は木の根）。並びは文書順。
///
/// **範囲が既に閉じた祖先は親にしない** — 子の範囲 ⊆ 親の範囲 を、範囲を
/// 相手にするコマンド全部が前提にしているため。

/// 使うので、添字と取り出し方だけを受ける形にしてある。
fn parent_indices(
  n : Int,
  depth_at : (Int) -> Int,
  from_at : (Int) -> Int,
  to_at : (Int) -> Int,
) -> Array[Int] {
  let out = Array::make(n, -1)
  let stack : Array[Int] = []
  for i = 0; i < n; i = i + 1 {
    while stack.length() > 0 &&
          (
            depth_at(stack[stack.length() - 1]) >= depth_at(i) ||
            to_at(stack[stack.length() - 1]) <= from_at(i)
          ) {
      ignore(stack.unsafe_pop())
    }
    out[i] = if stack.length() > 0 { stack[stack.length() - 1] } else { -1 }
    stack.push(i)
  }
  out
}
```

```typescript
  /** ルート直下の枝を、側ごとにグループへ切り分ける（文書順） */
  const sideGroups = (root: NodeInfo, left: boolean): NodeInfo[][] => {
    const out: NodeInfo[][] = [];
    for (const k of kidsOf(root)) {
      if (k.left !== left) continue;
      const last = out[out.length - 1];
      if (last && last[0].group === k.group) last.push(k);
      else out.push([k]);
    }
    return out;
  };

  /** グループ列を縦に積んだ高さ（グループの間は GAP.group） */
  const groupsH = (groups: NodeInfo[][]): number => {
    let sum = 0;
    for (let g = 0; g < groups.length; g++) {
      sum += (g === 0 ? 0 : GAP.group) + stackH(groups[g]);
    }
    return sum;
  };

  /** 木ぜんぶが縦にどれだけ要るか（左右のうち高いほう） */
  const treeH = (root: NodeInfo): number =>
    Math.max(
      sizeOf(root).h,
      groupsH(sideGroups(root, false)),
      groupsH(sideGroups(root, true)),
    );

  /**
   * 木の根を置く。**グループと左右はルート直下にしか無い**ので、根の子だけが
   * ここを通り、孫から下は `place` がそのまま面倒を見る。区切りの無い文書では
   * 右のグループが 1 つあるだけになり、置き方は従来（片側 1 列）と一致する。
   */
  const placeTree = (root: NodeInfo, top: number): number => {
    const size = sizeOf(root);
    const span = treeH(root);
    const sides = [
      { left: false, dir: 1 as const, groups: sideGroups(root, false) },
      { left: true, dir: -1 as const, groups: sideGroups(root, true) },
    ];
    let centerY = top + span / 2;
    for (const s of sides) {
      if (s.groups.length === 0) continue;
      const nearX = s.dir === 1 ? size.w + GAP.x : -GAP.x;
      let y = top + Math.max(0, (span - groupsH(s.groups)) / 2);
      const centers: number[] = [];
      for (let g = 0; g < s.groups.length; g++) {
        if (g > 0) {
          // 継ぎ目の線は、隣り合うグループの間の真ん中に、
          // その 2 グループでいちばん広い枝の幅で引く
          const near = [...s.groups[g - 1], ...s.groups[g]];
          const w = Math.max(...near.map((k) => sizeOf(k).w));
          seams.push({
            x: s.dir === 1 ? nearX : nearX - w,
            y: y + GAP.group / 2,
            w,
          });
          y += GAP.group;
        }
        const kids = s.groups[g];
        for (let i = 0; i < kids.length; i++) {
          y += gapBefore(i);
          centers.push(place(kids[i], nearX, y, s.dir));
          y += heightOf(kids[i]);
        }
      }
      // 根の中心は右の枝に合わせる（右が無ければ左）。区切りの無い文書で
      // 従来と 1px も変えないための取り決めで、両側にあるときも
      // 「どちらに合わせるか」を決めておかないと揺れる
      if (!s.left || sides[0].groups.length === 0) {
        centerY = (centers[0] + centers[centers.length - 1]) / 2;
      }
    }
    boxes.set(root.id, {
      n: root,
      x: 0,
      y: centerY - size.h / 2,
      w: size.w,
      h: size.h,
      rows: rowsOf.get(root.id) ?? [],
    });
    return centerY;
  };
```

```typescript
export function edgeEnds(L: Layout, id: number): { from: Pt; to: Pt } | null {
  const b = L.boxes.get(id);
  const pid = L.parentOf.get(id);
  const p = pid === undefined ? undefined : L.boxes.get(pid);
  if (!b || !p) return null;
  // 線は「親の、子が伸びる側の辺」から出て「子の、親を向いた辺」へ入る
  const out = dirOf(b.n) === 1 ? rightOf(p) : leftOf(p);
  const into = dirOf(b.n) === 1 ? leftOf(b) : rightOf(b);
  return { from: { x: out.x, y: out.y + (L.fanOf.get(id) ?? 0) }, to: into };
}
```

```moonbit
// ---- 境界を書く ----
//
// 書くのは**操作と掃除だけ**（ルート脇へのドラッグ / Mod+ドロップ / Flip side）。
// md を手打ちしたときは読むだけで、勝手に書き直さない。

///|
/// 境界 1 つぶんの本文。`flip` なら 2 行、そうでなければ 1 行。
///
/// **列はルートの形が決める。** リスト項目のルートなら、その項目の中身の列まで
/// 字下げする — 列 0 に書くと、外の CommonMark パーサはそこで外側のリストを
/// 閉じ、木そのものが割れる（insert_content と同じ理屈）。
fn sep_body(root_depth : Int, flip : Bool) -> String {
  let line = spaces(content_col_for(root_depth)) + "---" + eol
  if flip { line + line } else { line }
}

///|
/// 境界をブロックの境目 `at` へ書き入れる編集。前後の空行の出し分けは
/// 見出しの挿入（insert_heading_edit）と同じ式。
fn insert_sep_edit(at : Int, root_depth : Int, flip : Bool) -> Edit {
  let sb = StringBuilder::new()
  if at > 0 && code_at(st.text, at - 1) != 10 {
    sb.write_string(eol)
    sb.write_string(eol)
  } else if !preceded_by_blank(at) {
    sb.write_string(eol)
  }
  sb.write_string(sep_body(root_depth, flip))
  if at != st.text.length() {
    sb.write_string(eol)
  }
  Edit::{ from: at, to: at, insert: sb.to_string(), removed: "" }
}

///|
/// 既にある境界を、`flip` の正規形に書き直す編集。
fn set_sep_edit(b : Bound, root_depth : Int, flip : Bool) -> Edit {
  Edit::{
    from: b.start,
    to: b.end,
    insert: sep_body(root_depth, flip),
    removed: slice(st.text, b.start, b.end),
  }
}

///|
/// 境界を消す編集。**直後の空行も 1 つ道連れにする** — 残すと空行が 2 つ
/// 並んで、次に書くものの前後の空行の判定が狂う。
fn remove_sep_edit(b : Bound) -> Edit {
  let n = st.text.length()
  let mut to = b.end
  // 直後の空行 1 つぶん（あれば）
  let mut p = to
  while p < n && is_space(code_at(st.text, p)) {
    p = p + 1
  }
  if p < n && code_at(st.text, p) == 13 {
    p = p + 1
  }
  if p < n && code_at(st.text, p) == 10 {
    to = p + 1
  }
  Edit::{ from: b.start, to, insert: "", removed: slice(st.text, b.start, to) }
}

///|
/// ノード添字 → その木の根の添字。
fn root_index_of(i : Int) -> Int {
  let mut k = i
  while st.nodes[k].parent != -1 {
    let up = find_node(st.nodes[k].parent)
    if up < 0 {
      break
    }
    k = up
  }
  k
}

///|
/// その木（根の添字）の中にある境界だけ、文書順。グループ g の手前の境界は
/// `tree_bounds(root)[g - 1]`（グループは 0 始まり、境界を 1 つ越えるたび +1）。
fn tree_bounds(root : Int) -> Array[Bound] {
  let nd = st.nodes[root]
  let out : Array[Bound] = []
  for b in st.bounds {
    if b.start > nd.from && b.start < nd.to {
      out.push(b)
    }
  }
  out
}
```

`core/seps.mbt` の末尾に:

```moonbit
// ---- 掃除 ----
//
// **不変条件: どの操作の前後でも、操作対象でないグループの側は変わらない。**
//
// グループが空になると両脇の境界が隣り合う。読みの規則（1 本 = 分割 /
// 2 本以上 = 切り替え）は足し算にならないので、隣り合ったものは xor して
// 1 つに書き直す:
//   分割 + 分割 = 分割 / 分割 + 切り替え = 切り替え / 切り替え + 切り替え = 分割
//
// **触ってよいのは「直前まで境界として効いていた行」だけ。** 見分けるために、
// 編集の前に境界の位置を控え、ノード id と同じ仕掛け（map_offsets）で編集を
// またいで写す。手で書いた本文の `---` は控えに入らないので、決して触らない。

///|
/// 掃除の目印 = 編集前に効いていた境界。位置は `map_offsets` で写すので
/// `Array[Int]`、flip は**同じ添字**の別配列（組の配列にすると写せない）。
priv struct SepMarks {
  at : Array[Int]
  flip : Array[Bool]
}

///|
fn sep_marks() -> SepMarks {
  let at : Array[Int] = []
  let flip : Array[Bool] = []
  for b in st.bounds {
    at.push(b.start)
    flip.push(b.flip)
  }
  SepMarks::{ at, flip }
}

///|
/// 空いたグループの境界を畳む。`from_set` 以降に積まれた編集集合をまたいで
/// 目印を写してから、いまの文書と突き合わせる。
///
/// 判断は 2 つだけ:
///   - いま効いている境界に**目印が 2 つ以上**入っている = 空いてくっついた。
///     正しい flip は行数ではなく**元の flip の xor**（1 本 + 1 本 = 2 行だが、
///     反転 0 回なので分割のまま、という食い違いがここで起きる）
///   - 目印がどの境界にも入っていない = 効かなくなった（末尾のグループが
///     空いた）。その行は消す
fn sweep_seps(marks : SepMarks, from_set : Int) -> Unit {
  for k = from_set; k < st.last_sets.length(); k = k + 1 {
    map_offsets(marks.at, st.last_sets[k])
  }
  let set : Array[Edit] = []
  for b in st.bounds {
    let mut hit = 0
    let mut flip = false
    for k = 0; k < marks.at.length(); k = k + 1 {
      let m = marks.at[k]
      if m >= b.start && m < b.end {
        hit = hit + 1
        if marks.flip[k] {
          flip = !flip
        }
      }
    }
    if hit >= 2 && flip != b.flip {
      set.push(set_sep_edit(b, root_depth_at(b.start), flip))
    }
  }
  for k = 0; k < marks.at.length(); k = k + 1 {
    let m = marks.at[k]
    if m < 0 {
      continue // 編集そのものに飲まれて消えた
    }
    let mut alive = false
    for b in st.bounds {
      if m >= b.start && m < b.end {
        alive = true
        break
      }
    }
    if !alive {
      match dangling_run_at(m) {
        Some(b) => set.push(remove_sep_edit(b))
        None => ()
      }
    }
  }
  if set.length() > 0 {
    apply_sets([sort_edits(set)], "")
  }
}
```

補助が 3 つ要る（同じファイルに書く）:

```moonbit
///|
/// 位置 `at` にある区切り行のかたまり（境界として効いていなくても拾う）。
/// 掃除で「もう境界ではなくなった行」を消すのに使う。
fn dangling_run_at(at : Int) -> Bound? {
  for r in st.seps {
    if at >= r.start && at < r.end {
      return Some(Bound::{ start: r.start, end: r.end, flip: r.lines >= 2 })
    }
  }
  None
}

///|
/// その位置を含む木の、ルートの深さ（境界を書く列を決めるのに要る）。
fn root_depth_at(at : Int) -> Int {
  for i = st.nodes.length() - 1; i >= 0; i = i - 1 {
    if st.nodes[i].from < at {
      return st.nodes[root_index_of(i)].depth
    }
  }
  1
}

///|
/// 編集集合は昇順・非重複でなければならない（apply_edit_set の約束）。
fn sort_edits(set : Array[Edit]) -> Array[Edit] {
  let out = set
  for i = 1; i < out.length(); i = i + 1 {
    let e = out[i]
    let mut j = i - 1
    while j >= 0 && out[j].from > e.from {
      out[j + 1] = out[j]
      j = j - 1
    }
    out[j + 1] = e
  }
  out
}
```

そして共通の括弧:

```moonbit
///|
/// 構造を変えるコマンドを、掃除つきで走らせる。掃除は同じトランザクションに
/// 積むので **undo は 1 回**。既にトランザクションが開いていればそれに乗る。
fn with_sweep(body : () -> Unit) -> Unit {
  let opened = match st.tx {
    None => {
      begin_tx("")
      true
    }
    Some(_) => false
  }
  let marks = sep_marks()
  let base = st.last_sets.length()
  body()
  let keep = st.focus
  sweep_seps(marks, base)
  st.focus = keep
  if opened {
    commit_tx()
  }
}
```

```moonbit
///|
/// そのノードの属するグループを**丸ごと反対側へ**。
///
/// 実体は「両脇の境界の flip を反転する」だけ。両方を反転するので、
/// **そのグループだけが移り、下のグループは 1 つも動かない**。
/// 手前に境界が無い（= 先頭のグループ）ときは、そのグループの**最初の枝の
/// 手前**に切り替えを書き足す — 「全部左」はこれで表せる。
///
/// 書き足す位置を「ルート見出しの直後」にしないのは、そこが**ブロックの
/// 境目ではない**ため（見出しの次の行は空行で、そこへ入れると空行が 2 つ
/// 並ぶ）。枝の行頭は必ずブロックの境目なので、前後の空行が正しく出る。
fn cmd_flip_side(id : Int) -> Unit {
  let i = find_node(id)
  if i < 0 {
    return
  }
  let ri = root_index_of(i)
  let root = st.nodes[ri]
  let root_id = root.id
  let g = st.nodes[i].group
  let bounds = tree_bounds(ri)
  let set : Array[Edit] = []
  // 後ろの境界（あれば）を先に積む — 編集は昇順でなければならない
  if g < bounds.length() {
    set.push(set_sep_edit(bounds[g], root.depth, !bounds[g].flip))
  }
  if g > 0 {
    set.push(set_sep_edit(bounds[g - 1], root.depth, !bounds[g - 1].flip))
  } else {
    // 先頭のグループ: その最初の枝の手前へ切り替えを書き足す
    let mut first_from = -1
    for nd in st.nodes {
      if nd.parent == root_id && nd.group == 0 {
        first_from = nd.from
        break
      }
    }
    if first_from < 0 {
      return // 直下の枝が無い = 動かすものが無い
    }
    set.push(insert_sep_edit(first_from, root.depth, true))
  }
  if set.length() == 0 {
    return
  }
  with_sweep(fn() { apply_sets([sort_edits(set)], "") })
  st.focus = id
}
```

```moonbit
///|
/// 選んだ枝を、その側の**末尾**へ。ルートの脇へ素でドラッグしたときの実体。
///
/// 規則は 2 つだけ:
///   - その側にグループがある → 区切りは書かない。最後のグループの末尾へ入れる
///   - その側にグループが無い → ルートの範囲の末尾に切り替え + 枝
///
/// 「無い側」に置くとき手前は必ず反対側なので、**素のドラッグが書く境界は
/// 常に切り替え**（分割を書くことは無い）。
fn cmd_move_side_end(ids : Array[Int], root : Int, left : Bool) -> Unit {
  let ri = find_node(root)
  if ri < 0 {
    return
  }
  // その側の最後の直下の枝
  let mut last = -1
  for i = 0; i < st.nodes.length(); i = i + 1 {
    let nd = st.nodes[i]
    if nd.parent == root && nd.left == left {
      last = nd.id
    }
  }
  with_sweep(fn() {
    let order : Array[Int] = []
    for k in normalize_selection(ids) {
      order.push(st.nodes[k].id)
    }
    let rehide = unhide_for_move(order)
    if last >= 0 {
      // その側の最後のグループの末尾へ（区切りは書かない）
      ignore(move_steps(ids, last, 2))
    } else {
      // その側は空。ルートの最後の子にしてから、その手前に切り替えを書く
      let first = move_steps(ids, root, 0)
      if first >= 0 {
        let i = find_node(first)
        if i >= 0 {
          let at = st.nodes[i].from
          apply_sets([[insert_sep_edit(at, st.nodes[find_node(root)].depth, true)]], "")
        }
      }
    }
    for id in rehide {
      cmd_toggle_hidden(id)
    }
  })
}
```

```moonbit
///|
/// 選んだ枝を、`target` の直前 / 直後へ**新しいグループ**として置く。
///
/// 決め方は 1 つ: **置いた場所の手前と後ろの境界を、側がつながるように直す
/// （無ければ足す）**。既にあるグループの真ん中に置けば、その規則の結果と
/// してそのグループが 2 つに割れる（割るための特別な処理は持たない）。
fn cmd_move_new_group(
  ids : Array[Int],
  target : Int,
  before : Bool,
  left : Bool,
) -> Unit {
  let ti = find_node(target)
  if ti < 0 {
    return
  }
  let root_id = st.nodes[root_index_of(ti)].id
  with_sweep(fn() {
    // 1) まず動かす。境界を書くのは、位置が決まってから
    let order : Array[Int] = []
    for k in normalize_selection(ids) {
      order.push(st.nodes[k].id)
    }
    let rehide = unhide_for_move(order)
    let first = move_steps(ids, target, if before { 1 } else { 2 })
    for id in rehide {
      cmd_toggle_hidden(id)
    }
    let ri = find_node(root_id)
    if first < 0 || ri < 0 {
      return
    }
    let root_depth = st.nodes[ri].depth
    // 2) 動かした塊の範囲。**id は移動をまたいで生きている**ので、
    //    動かしたものを引き直して端を取る
    let mut head_from = -1
    let mut tail_to = -1
    for id in order {
      let i = find_node(id)
      if i < 0 {
        continue
      }
      let nd = st.nodes[i]
      if head_from < 0 || nd.from < head_from {
        head_from = nd.from
      }
      if nd.to > tail_to {
        tail_to = nd.to
      }
    }
    if head_from < 0 {
      return
    }
    // 3) 塊の手前・後ろにある「ルート直下の枝」の側
    let mut prev : Node? = None
    let mut next : Node? = None
    for nd in st.nodes {
      if nd.parent != root_id {
        continue
      }
      if nd.to <= head_from {
        prev = Some(nd)
      } else if nd.from >= tail_to && next is None {
        next = Some(nd)
      }
    }
    // 4) 手前と後ろの境界を、側がつながるように直す。
    //    後ろから積む（編集集合は昇順でなければならない）
    let bounds = tree_bounds(ri)
    let set : Array[Edit] = []
    match next {
      Some(nx) => {
        let want = left != nx.left
        // 塊と次の枝の**間**に境界があればそれを直す。無ければ足す
        match first_bound_after(bounds, tail_to) {
          Some(b) =>
            if b.start < nx.from {
              set.push(set_sep_edit(b, root_depth, want))
            } else {
              set.push(insert_sep_edit(tail_to, root_depth, want))
            }
          None => set.push(insert_sep_edit(tail_to, root_depth, want))
        }
      }
      None => () // 末尾に置いた = 後ろの境界は要らない
    }
    match prev {
      Some(pv) => {
        let want = pv.left != left
        match last_bound_before(bounds, head_from) {
          Some(b) =>
            if b.start >= pv.to {
              set.push(set_sep_edit(b, root_depth, want))
            } else {
              set.push(insert_sep_edit(head_from, root_depth, want))
            }
          None => set.push(insert_sep_edit(head_from, root_depth, want))
        }
      }
      None =>
        // 手前に枝が無い = 先頭のグループ。側は右から始まるので、
        // 左にしたいときだけルート直後に切り替えを書く
        if left {
          set.push(insert_sep_edit(head_from, root_depth, true))
        }
    }
    if set.length() > 0 {
      apply_sets([sort_edits(set)], "")
    }
  })
}
```

```moonbit
/// `cross` ならグループの壁を越える（越えた先の側になる）。
fn cmd_reorder(id : Int, dir : Int, cross : Bool) -> Unit {

    let rehide = unhide_for_move([id])
```

```typescript
// 区切りを書いた文書が、**外の Markdown パーサでも同じ木に読める**こと。
//
// リストの形では、区切りを列 0 に書くと外の CommonMark パーサはそこで
// 外側のリストを閉じ、続く項目が別の木になる。字下げの規則（core が持つ）が
// 効いていることを、実物のパーサに読ませて確かめる。
//
// 実行: pnpm test

import { test } from "node:test";
import assert from "node:assert/strict";
import { parser } from "@lezer/markdown";
import { core, initDoc, getText, idOf } from "./_helpers.ts";

/** その md を CommonMark として読み、リスト項目のラベルを入れ子の深さつきで返す */
function itemsOf(md: string): { depth: number; text: string }[] {
  const tree = parser.parse(md);
  const out: { depth: number; text: string }[] = [];
  let depth = 0;
  tree.iterate({
    enter: (n) => {
      if (n.name === "BulletList") depth++;
      if (n.name === "ListItem") {
        const line = md.slice(n.from, n.to).split("\n")[0];
        out.push({ depth, text: line.replace(/^\s*[-*+]\s*/, "").trim() });
      }
    },
    leave: (n) => {
      if (n.name === "BulletList") depth--;
    },
  });
  return out;
}

test("リストの形で境界を書いても、外のパーサの木は変わらない", () => {
  const snap = initDoc("- root\n\n  - a\n\n  - b\n");
  const before = itemsOf(getText());
  // b を左へ（切り替えの境界が書かれる）
  core.moveSideEnd([idOf(snap.nodes, "b")], idOf(snap.nodes, "root"), true);
  const after = itemsOf(getText());
  assert.deepEqual(
    after.map((i) => i.depth),
    before.map((i) => i.depth),
    `字下げが崩れている:\n${getText()}`,
  );
});
```
