# verbatim — 読んだ綴りは保ち、新しいものだけ綴る 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 名前は md の 1 行の原文としてそのまま書き、項目の中の見出しは子として読み、名前で断る規則を消す（PR 1）。読んだ綴り（中身の原文・境界・水平線・項目のマーカー・見出しの書き方）を木に持ち、書くときはそれを返す（PR 2）。

**Architecture:** 読む側（`build.mbt`）は今も原文を切り出している。書く側（`unbuild.mbt`）が名前と中身を md として読み直してライブラリに綴らせているのをやめ、**生の行・生の塊（`HtmlBlock` / `HtmlInline`）としてライブラリを素通しさせる**。ライブラリの `serialize` はブロックの並びと字下げだけを担う。綴りは `Block.raw` / `Root.rules` / `ListNode` と `HeadingNode` の欄に持ち、mmm が新しく作るものだけ既定で綴る。merge は既に行・中身の粒度で差分を書くので触らない（`serialize` / `fragment` が原文を返すことで安全網が閉じる）。

**Tech Stack:** MoonBit（core）、TypeScript、Node `node:test`。

**Spec:** `docs/superpowers/specs/2026-09-06-verbatim-design.md`

| md | 木 |
