# 境界の読み直し — #312 #315 #319

`---` が左右を裏返す（境界）かどうかを、**見出しの根と項目の根で別々の規則**で決めていた。
その継ぎ目から 3 つの食い違いが出ている。

| 形 | いまの読み | 何が起きるか |
|---|---|---|
| `---` / `- a` | 境界になれない（根が無い）のに、`a` を深さ 2 に置く | 行の無い根が立ち、読んだ直後に `GappedItem`。後ろの段落を抱えて #312 #315 の出どころになる |
| `- a` / `---`（列 0）/ `- b` | 項目の根に「口」があるとして `b` を `a` の左の子にする | 読みが左を作り、検めが `ListSide` で書けないと言う |
| `- r` の中の `---` / `- a` | 項目の中の `---` は常に飾り | 項目の根は左を持てない。#319 は地図の側でその穴を塞いだ |

**直すのは規則の置き場所。** 見出しは文書の段、項目は `<li>` の中、と入れ物で分けていたのを、
**木の上の所属（誰の body に居るか）** 1 つで決める。

## 決まったこと（2026-09-15、作者）

1. **境界の条件。** md が水平線と読んだもののうち、**いずれかのノードの body に居て**
   （文書の body は含まない）、**直後が同じ木の骨格の行**であるものだけが境界。
   空行は条件に入れない — 水平線かどうか（setext の下線ではないか）は md の文法が決めている
2. **境界は直後の行を深さ 2 へ引き出す。** 項目の中からでも引き出す。見出しの深さは
   Implicit が保つ（今と同じ）
3. **項目の body。**
   - 項目の body は、その項目の段に書かれた、ラベル以外の塊（入れ子の項目の段に書かれたものは入れ子の側）
   - 見出しは節として範囲を取る（文書の中でも項目の中でも）
   - 字下げが戻った塊は、そこより深い項目を閉じる（列 0 なら全部）
4. **表は扱わない。** 列 0 に続けた表が項目の名前になる件はライブラリの読みのずれで、表の issue で扱う

「口」（深さ 2 の引き出し先があるか）は捨てる。項目の根の「右だけ」（#319 の `two_sided` / `ListSide`）も捨てる —
項目の根も見出しの根と同じく左右を持ち、書き方は項目の中の `---`。

## 規則

### body の持ち主

塊が座るのは、**その塊の手前で開いている骨格の行のうち、塊の桁が属するもの**。

- 文書の段（列 0、どのリストの外）では、開いている一番深い見出し。無ければ文書
- `<li>` の中では、その項目自身。ただし項目の中に見出しがあれば、その見出しの節
- 入れ子のリストの後ろで、字下げがその項目の段まで戻った塊は、入れ子を閉じてその項目のもの

**持ち主は行で決まり、深さでは決まらない。** 境界が枠を深さ 2 へ引き出したあとも、
`<li>` の中に残った塊の持ち主はその `<li>` の項目（決めてほしいこと ①）。

### 境界

水平線を 1 本読んだら、行き先が決まるまで保留する。持ち主は書かれた所で控える。

```
次の塊は？
  中身・水平線       → 線（持ち主の body の尻）
  骨格の行
    持ち主が文書     → 線（文書の body）
    行が新しい木     → 線（持ち主の body の尻）
    それ以外         → 境界（その行を深さ 2 へ引き出し、側を 1 回裏返す）
  文末               → 線
```

「新しい木」は深さ 1 に座る行 — `# s`、または文書の段の列 0 の項目。

**型は変わらない。** 側は根の子だけが持ち（`Root.sides`）、境界の綴りは `Root.rules`。
変わるのは、どの `---` がそこへ届くかだけ。

## 例

`/` は行の区切り。字下げは `(r)` のように持ち主の段で言う。**✱ はいまと答えが変わる形。**

### 見出しの根

| md | 木 |
|---|---|
| `# r` / `## a` / `---` / `## b` | r → [a, (境界)b]。b は左 |
| `# r` / `---` / `## a` | r → [(境界)a]。a は左 |
| `# r` / `## a` / `---` / `### x` | r → [a, (境界)Implicit → x]。x は左 |
| `# r` / `## a` / `### x` / `---` / `### y` | r → [a → x, (境界)Implicit → y]。y は左 |
| `# r` / `## a` / `---` / `- b` / `- c` | r → [a, (境界)b, c]。b と c は左 |
| `# r` / `## a` / `---` / `---` / `## b` | r → [a（中身: 線）, (境界)b] |
| `# r` / `---` / `# s` | r（中身: 線）。s は別の木 |
| `# H` / `- r` / `---` / `- c` | H → [r, (境界)c]。`---` は H の body（列 0 が r を閉じる） |

### 文書の body

| md | 木 |
|---|---|
| `---` / `## a` | 文書（中身: 線）。Implicit → a |
| ✱ `---` / `- a` | 文書（中身: 線）。a は根 |
| `body` / `---` / `# a` | 文書（中身: body, 線）。a は根 |
| `- a` / `---` / `## b` | 文書（中身: 線）。a と Implicit → b は別の木 |
| ✱ `- a` / `---` / `- b` | 文書（中身: 線）。a と b は別の木 |
| ✱ `- r` / `(r) - b` / `---` / `(r) - c` | r → [b]。文書（中身: 線）。c は別の木（字下げ 2 でも列 0 の水平線の後ろは新しいリスト） |

### 項目の根

| md | 木 |
|---|---|
| ✱ `- r` / `(r) ---` / `(r) - a` | r → [(境界)a]。a は左 |
| ✱ `- r` / `(r) ---` / `(r) # head` | r → [(境界)head]。head は左 |
| ✱ `- r` / `(r) ---` / `(r) - a` / `(r) ---` / `(r) # b` | r → [(境界)a, (境界)b]。a は左、b は右 |
| ✱ `- r` / `(r) - b` / `(b) ---` / `(r) - c` | r → [b, (境界)c]。c は左 |
| ✱ `- r` / `(r) - b` / `(b) ---` / `(b) - x` | r → [b, (境界)x]。x は左（b の中から引き出す） |
| `- r` / `(r) ---`（文末） | r（中身: 線） |
| `- r` / `(r) ---` / `- s` | r（中身: 線）。s は別の木 |
| `- r` / `---`（列 0） | r。文書（中身: 線） |
| `- r` / `  ---`（空行無し） | 項目 "" → Implicit → 見出し r（setext の下線。水平線ではない） |

### 根でない項目

| md | 木 |
|---|---|
| ✱ `# R` / `- r` / `(r) ---` / `(r) - x` | R → [r, (境界)x]。x は左（孫の見出しの `### x / --- / ### y` と同じ形） |

### 項目の body

| md | 木 |
|---|---|
| `- r` / `(r) text` | r（中身: text） |
| `- r` / `(r) - a` / `(a) text` | r → [a（中身: text）] |
| ✱ `- r` / `(r) - a` / `(r) text` | r（中身: text） → [a] |
| ✱ `- r` / `(r) - a` / `(r) text` / `(r) - b` | r（中身: text） → [a, b] |
| `- r` / `(r) - a` / `text`（列 0） | r → [a]。文書（中身: text） |
| `# H` / `- r` / `(r) - a` / `text`（列 0） | H（中身: text） → [r → [a]] |
| `- r` / `(r) # h` / `(r) text` | r → [h（中身: text）]（見出しは節） |

## 書き戻しの綴り

側の変わり目は、**根の子の列の中で**、変わる子の手前に `---` を 1 本書く（読んだ綴りが在ればそれ）。

- 見出しの根: 文書の段（今と同じ）
- 項目の根: **根の項目の段**（ラベルの桁）。入れ子のリストはそこで 2 つに割れ、
  `---` は根の body の尻に読まれて、直後の子が境界になる

## 決めてほしいこと

① **引き出した後の、同じ `<li>` の中身。**

```md
- r
  - b

    ---

    - x

    text
```

`x` は深さ 2 の左へ引き出す（決まったこと 2）。`text` は b の段に書かれている。

| 案 | text の持ち主 | 書き戻すと |
|---|---|---|
| **b（推し）** | 桁が言うとおり b | `- r` / `(r) - b` / `(b) text` / `(r) ---` / `(r) - x` — text が x の手前へ移るが、木は同じ |
| x | 境界の後ろは引き出した行の節 | `(x) text` — x の段へ字下げが深くなる |

推しの理由: **境界が動かすのは骨格の行だけ**で、中身の持ち主は桁が決める（決まったこと 3）。
見出しの節（`### x / --- / ### y / text` の text は y）と違うのは、見出しには入れ物が無く、
項目には `<li>` が在るから。

② **根でない項目の中の `---`**（例の表「根でない項目」）。決まったこと 1 をそのまま当てると、
`# R` / `- r` / `(r) ---` / `(r) - x` の x は r の外へ引き出されて左になる。
孫の見出し（`### x / --- / ### y`）と同じ形なので推しはこのまま。

5. **#315 を測り直す** — 行の無い根が body を抱える形は、文書が `##` から始まる根だけになるはず
