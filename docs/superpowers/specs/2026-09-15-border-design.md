# 境界の読み直し — #312 #315 #319

`---` が左右を裏返す（境界）かどうかを、**見出しの根と項目の根で別々の規則**で決めていた。
その継ぎ目から 3 つの食い違いが出ている。

| 形 | いまの読み | 何が起きるか |
|---|---|---|
| `---` / `- a` | 境界になれない（根が無い）のに、`a` を深さ 2 に置く | 行の無い根が立ち、読んだ直後に `GappedItem`。後ろの段落を抱えて #312 #315 の出どころになる |
| `- a` / `---`（列 0）/ `- b` | 項目の根に「口」があるとして `b` を `a` の左の子にする | 読みが左を作り、検めが `ListSide` で書けないと言う |
| `- r` の中の `---` / `- a` | 項目の中の `---` は常に飾り | 項目の根は左を持てない。#319 は地図の側でその穴を塞いだ |

**直すのは規則の置き場所。** 見出しは文書の段、項目は `<li>` の中、と入れ物で分けていたのを、
**木の上の所属（誰の body に居るか）** 1 つで決める。

## 決まったこと（2026-09-15、作者）

1. **境界の条件。** md が水平線と読んだもののうち、**いずれかのノードの body に居て**
   （文書の body は含まない）、**直後が同じ木の骨格の行**であるものだけが境界。
   空行は条件に入れない — 水平線かどうか（setext の下線ではないか）は md の文法が決めている。
   根でない項目の中でも同じ
2. **境界は根より深い行を閉じ、直後の行を反対側へ引き出す。深さは保つ。**
   見出しは `#` の数で、項目は**書かれた入れ物**で深さが決まる（`<li>` の中ならその項目の
   1 つ下、文書の段なら開いている見出しの 1 つ下）。足りない段は Implicit が埋める —
   見出しも項目も同じ
3. **境界が動かすのは骨格の行だけ。** 中身の持ち主は md どおり — 境界の後ろでも、
   `<li>` の中に残った塊はその項目のもの（「野菜につける」）
4. **項目の body。**
   - 項目の body は、その項目の段に書かれた、ラベル以外の塊（入れ子の項目の段に書かれたものは入れ子の側）
   - 見出しは節として範囲を取る（文書の中でも項目の中でも）
   - 字下げが戻った塊は、そこより深い項目を閉じる（列 0 なら全部）
5. **表は扱わない。** 列 0 に続けた表が項目の名前になる件はライブラリの読みのずれで、表の issue で扱う

「口」（深さ 2 の引き出し先があるか）は捨てる。項目の根の「右だけ」（#319 の `two_sided` / `ListSide`）も捨てる —
項目の根も見出しの根と同じく左右を持ち、書き方は項目の中の `---`。

### 決めの経緯

3 は 4 案から選んだ（例: `- 買い物` / `(買い物) - 野菜` / `(野菜) ---` / `(野菜) - 肉` / `(野菜) メモ` / `(野菜) - 魚`）。

| 案 | メモの持ち主 | 採らなかった理由 |
|---|---|---|
| 行の無い箱 | 左に立った Implicit | 読んだだけで中身を持つ Implicit が生まれる（#315 の形）。md で野菜の中に書いた字が、野菜でないものに付く |
| **野菜（採った）** | md の持ち主 | — |
| `---` を飾りと読む | 野菜（左右が起きない） | 境界かを決めるのに `---` のずっと後ろまで見る。下にメモを 1 行足すだけで、肉と魚が右へ戻る |
| どこにも属さない | 文書 | 境界の後ろの文章を文書へ回す専用の分岐が要る。字下げされた文章が文書の body に入り、どのノードからも辿れない |

「野菜」は読みの流れのままで例外が無い — 読みは今どの `<li>` の中かを知っており、境界が閉じるのは積んだ行だけ。
代わりに**野菜の地番が、左へ出た肉の行をまたぐ**（メモが肉より下に書かれている）。カーソルの持ち主は
既に区間を割って持つ（#204）ので平気で、md の薄塗りと写す範囲を同じく区間で持つ。

## 規則

### body の持ち主

塊が座るのは、**その塊を包む入れ物のうち一番内側で、開いている行**。

- 文書の段（列 0、どのリストの外）では、開いている一番深い見出し。無ければ文書
- `<li>` の中では、その項目自身。ただし項目の中に見出しがあれば、その見出しの節
- 入れ子のリストの後ろで、字下げがその項目の段まで戻った塊は、入れ子を閉じてその項目のもの

**持ち主は行で決まり、積んだ深さでは決まらない。** 境界が行を閉じても、`<li>` の中の塊の持ち主はその項目。

### 境界

水平線を 1 本読んだら、行き先が決まるまで保留する。持ち主は書かれた所で控える。

```
次の塊は？
  中身・水平線       → 線（持ち主の body の尻）
  骨格の行
    持ち主が文書     → 線（文書の body）
    行が新しい木     → 線（持ち主の body の尻）
    それ以外         → 境界（根より深い行を閉じ、深さを保って反対側へ置く）
  文末               → 線
```

「新しい木」は深さ 1 に座る行 — `# s`、または文書の段の列 0 の項目。

**型は変わらない。** 側は根の子だけが持ち（`Root.sides`）、境界の綴りは `Root.rules`。
変わるのは、どの `---` がそこへ届くかだけ。

## 例

`/` は行の区切り。字下げは `(r)` のように持ち主の段で言う。**✱ はいまと答えが変わる形。**

### 見出しの根

| md | 木 |
|---|---|
| `# r` / `## a` / `---` / `## b` | r → [a, (境界)b]。b は左 |
| `# r` / `---` / `## a` | r → [(境界)a]。a は左 |
| `# r` / `## a` / `---` / `### x` | r → [a, (境界)Implicit → x]。x は左 |
| `# r` / `## a` / `### x` / `---` / `### y` | r → [a → x, (境界)Implicit → y]。y は左 |
| `# r` / `## a` / `---` / `- b` / `- c` | r → [a, (境界)b, c]。b と c は左（文書の段の項目は開いている見出し r の 1 つ下） |
| `# r` / `## a` / `---` / `---` / `## b` | r → [a（中身: 線）, (境界)b] |
| `# r` / `---` / `# s` | r（中身: 線）。s は別の木 |
| `# H` / `- r` / `---` / `- c` | H → [r, (境界)c]。`---` は H の body（列 0 が r を閉じる） |

### 文書の body

| md | 木 |
|---|---|
| `---` / `## a` | 文書（中身: 線）。Implicit → a |
| ✱ `---` / `- a` | 文書（中身: 線）。a は根 |
| `body` / `---` / `# a` | 文書（中身: body, 線）。a は根 |
| `- a` / `---` / `## b` | 文書（中身: 線）。a と Implicit → b は別の木 |
| ✱ `- a` / `---` / `- b` | 文書（中身: 線）。a と b は別の木 |
| ✱ `- r` / `(r) - b` / `---` / `(r) - c` | r → [b]。文書（中身: 線）。c は別の木（字下げ 2 でも列 0 の水平線の後ろは新しいリスト） |

### 項目の根

| md | 木 |
|---|---|
| ✱ `- r` / `(r) ---` / `(r) - a` | r → [(境界)a]。a は左 |
| ✱ `- r` / `(r) ---` / `(r) # head` | r → [(境界)head]。head は左 |
| ✱ `- r` / `(r) ---` / `(r) - a` / `(r) ---` / `(r) # b` | r → [(境界)a, (境界)b]。a は左、b は右 |
| ✱ `- r` / `(r) - b` / `(b) ---` / `(r) - c` | r → [b, (境界)c]。c は左 |
| ✱ `- r` / `(r) - b` / `(b) ---` / `(b) - x` | r → [b, (境界)Implicit → x]。x は左で深さ 3（b の `<li>` の中なので） |
| ✱ `- r` / `(r) - b` / `(b) ---` / `(b) - x` / `(b) text` / `(b) - y` | r → [b（中身: text）, (境界)Implicit → [x, y]]。text は b のもの、y は x と同じ左 |
| `- r` / `(r) ---`（文末） | r（中身: 線） |
| `- r` / `(r) ---` / `- s` | r（中身: 線）。s は別の木 |
| `- r` / `---`（列 0） | r。文書（中身: 線） |
| `- r` / `  ---`（空行無し） | 項目 "" → Implicit → 見出し r（setext の下線。水平線ではない） |

### 根でない項目

| md | 木 |
|---|---|
| ✱ `# R` / `- r` / `(r) ---` / `(r) - x` | R → [r, (境界)Implicit → x]。x は左で深さ 3（孫の見出しの `### x / --- / ### y` と同じ形） |

### 項目の body

| md | 木 |
|---|---|
| `- r` / `(r) text` | r（中身: text） |
| `- r` / `(r) - a` / `(a) text` | r → [a（中身: text）] |
| ✱ `- r` / `(r) - a` / `(r) text` | r（中身: text） → [a] |
| ✱ `- r` / `(r) - a` / `(r) text` / `(r) - b` | r（中身: text） → [a, b] |
| `- r` / `(r) - a` / `text`（列 0） | r → [a]。文書（中身: text） |
| `# H` / `- r` / `(r) - a` / `text`（列 0） | H（中身: text） → [r → [a]] |
| `- r` / `(r) # h` / `(r) text` | r → [h（中身: text）]（見出しは節） |

## 読みの結果を使う側

境界の後ろに残った中身（決まったこと 3）で、**持ち主の地番が子孫でない行をまたぐ**ことが初めて起きる。
地番を 1 本の範囲で使う所は、カーソルの持ち主（`core/read/caret.mbt` の `owns`）と同じく区間を割って持つ。

| 使う所 | いま | 直す |
|---|---|---|
| カーソルの持ち主 | 子の後ろに書かれた中身を別の区間で持つ（#204） | そのまま |
| md の薄塗り（`ranges`） | 地番 1 本（子孫込み） | 自分の区間と子孫の地番 |
| 写す（`Mod+C`） | 地番 1 本 | 同上 |

## 書き戻しの綴り

側の変わり目は、変わる子の手前に `---` を 1 本書く（読んだ綴りが在ればそれ）。

- 見出しの根: 文書の段（今と同じ）
- 項目の根: **根の項目の段**（ラベルの桁）。入れ子のリストはそこで 2 つに割れ、
  `---` は根の body の尻に読まれて、直後の子が境界になる
- `Implicit → 項目`（深さを保って引き出した項目）: **手前の兄弟が項目のときだけ**書ける —
  その兄弟の `<li>` の尻に `---` と項目を書く。手前が見出しか先頭の子なら書けない（`GappedItem`）
- `<li>` の中の `---` は前後に空行を置く。空行が無いと直前の段落の setext の下線になり、段落が見出しに化ける

## 段

1. **仕様**（この文書と `docs/spec.md` / `docs/core.md` の書き替え）
2. **読み** — 持ち主を行で指す、境界の条件を 1 か所に、深さを保って引き出す、項目の段に戻った塊が入れ子を閉じる。例の表を試験に
3. **検めと地図と操作と読みを使う側** — `ListSide` を捨て、`BorderBreak` と `GappedItem` を境界の条件に揃え、#319 の制限を戻し、`haul` も深さを保つ。薄塗りと写す範囲を区間で持つ
4. **書き** — 項目の根の側と、境界の後ろの `Implicit → 項目` を書く。往復と冪等の総当たりで確かめる
5. **#315 を測り直す** — 行の無い根が body を抱える形は、文書が `##` から始まる根だけになるはず
