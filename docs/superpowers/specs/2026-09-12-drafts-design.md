# 控え（Drafts）の設計 — #306

#306 は「Autosave は人が入れるトグルで、一度も保存していない文書には何もしない」と言う。
**直す前に、2 つの言葉を割る。** 割らないと、同じ「自動保存」がディスクへ書くことと
ブラウザに控えることの両方を指し、どちらの話をしているか読めない。

| 語 | 何をする | 誰から見えるか |
|---|---|---|
| **Autosave**（いま在る） | ディスクの `.md` そのものに書く | git・他のエディタ・同期フォルダから見える |
| **Drafts**（これから作る） | ブラウザの中に本文を控える | mmm の中だけ |

## 決まったこと（2026-09-12、作者）

1. **Autosave は捨てる。** ディスクへ書くのは `Mod+S` / Save / Save as だけになる。
2. **Drafts は保存した後も残る。** 版として遡れる。

この 2 つで、issue の 3 つの問題点が全部閉じる。

| #306 の問題点 | どう閉じるか |
|---|---|
| 一度も保存していない文書がいちばん失いやすいのに、そこだけが Autosave の何もしない場所 | Drafts はディスクの置き場を要らない。**名前の無い文書がいちばんの客** |
| 既定が off なので、人が先に「落ちるかもしれない」と思っていないと効かない | Drafts にトグルは無い。**常に効く** |
| 「自動保存」と名乗るのに、残らないときの知らせが印と beforeunload しか無い | 残らないのは控えが取れなかったときだけで、そのときは言う |

## 原則を 1 つ書き替える

`docs/spec.md:1219-1221` はこう書いている。

> localStorage に残すのは**見た目と手触りの好みだけ**（テーマ・アクセントカラー・
> 書き出しのやり方・掴みやすさ・分割線の居場所）。本文の控えは持たない
> — 持てばディスクの `.md` と二重の真実になる

**Drafts はこの決めを覆す。** 覆すからには、二重の真実にならない理由を書く。

- **控えは「正」を名乗らない。** 開くのは常に人で、勝手には開き直さない
  （`docs/spec.md:475-479` の決めはそのまま）
- **控えから開いた文書は、印が立ったまま出る。** 「ディスクにこの字は無い」を
  最初から言っているので、どちらが正かを人が読める
- **控えは書き戻さない。** ディスクへ書くのは人が押したときだけ
- **ディスクの `.md` が正であることは変わらない。** 控えは、まだそこへ届いていない字と、
  そこへ届く前に通った字を覚えているだけ

localStorage の行はそのまま（見た目と手触りだけ）。**書き替えるのは IndexedDB の行**で、
「置くのはハンドルだけ」に控えが加わる。

## 形

### 1 件 = 1 レコード

```moonbit
/// 控え 1 つ。**1 件が 1 レコード** — 一覧を丸ごと 1 つの鍵に入れない
/// （入れると #300 と同じ、読みと書きが別の取引で食い合う形になる）
pub(all) struct Draft {
  /// 系列の id。1 つの編集の流れに 1 つ（`load_text` で振り直す）
  flow : String
  /// 系列の中の版。0 から増える
  seq : Int
  /// 見出しに出す名前。保存済みならファイル名、まだならば本文から導いたもの
  name : String
  /// 最後に書いた時刻
  at : Double
  /// 本文。**生で置く** — gzip は非同期の段と失敗の口を 1 つ増やすわりに、
  /// 上限（20 MB）が件数より先に当たらないので効かない
  text : String
  /// その文書のファイル。控えから開いたとき Save の行き先が要る。
  /// まだ保存していない文書では None
  doc : @web.FileHandle?
}
```

鍵は `"<flow>/<seq>"`。置き場は Recent と同じ DB（`mmm`）の**別の棚**（`drafts`）。
棚を増やすので DB の版は 1 → 2 に上がる。

一覧を読むには棚の全部が要るので、`@web` に `idb_all` を 1 つ足す
（いまは `idb_get` / `idb_put` / `idb_delete` の 3 つ）。

### 引き金

いまの `write_soon`（`@web.Quiet`。#299 で捨てる口が付いた）を**そのまま付け替える**。

```
前: dirty && autosave && saved_name is Some(_)  → ディスクへ書く
後: text() != 控えた字                          → 控える
```

条件から `can_hold`（ファイルを持てる環境か）が落ちる。**控えるのに置き場は要らない。**
間合いは `quiet = 1000` のまま（打鍵が止まって 1 秒）。ディスクより安い書き先なので
伸ばす理由が無い。

`load_text` は `write_soon` を捨て（#299）、そのうえで**新しい系列を振る**。
New / Open / Discard / 共有リンク / 落とされた md が全部ここを通る。

## 版の切り方

**時間 1 つで測る。** 前の版を書いてから 5 分経っていれば次の版、経っていなければ
同じ版を上書きする。1 系列は 3 版まで（＝直近 15 分ぶん遡れる）。

字数で測らない理由: 打って消せば元へ戻るので、「大きく変えた」を字数の差では言えない。
大改稿ほど差が小さく出ることがある。時間は戻らない。しかも**一覧に出すのが時刻**なので、
なぜ行が 2 つあるかを説明無しに読める。

節目（New / Open / Discard）は系列そのものが変わるので、版の物差しには乗せない。

## 上限と捨て方

| 何 | 数 | あふれたら |
|---|---|---|
| 系列 | 20 | いちばん古い系列を丸ごと |
| 全体 | 20 MB | 同上 |

Recent の `keep = 20` と同じ数にする（覚える数字を増やさない）。期限は置かない
— 落ちた直後に見たいものが日付で消えるのは、約束として弱い。

**捨てるのは 2 つの場合だけ。** 上限に当たったときと、人が消したとき。
保存しても捨てない（決め 2）。

人が消す道は `Forget all drafts` の 1 行（Files の中）。1 件ごとの `×` は置かない
— Recent の行が `×` を持たないので、同じ器に 2 通りの行ができる。

## 見え方

### 一覧

Files に `Drafts ▸` の入れ子を足す（`Recent ▸` の隣）。立ち上がりの真ん中（#277）にも
`Caption` を 2 つ並べ、**Drafts を上**に置く。Recent は「また開きたいもの」、Drafts は
「まだ失われうるもの」で、急ぐのは後者。

引き口は 1 つに保つ。`app/app.mbt:562-564` が「並びは Files の `Recent ▸` と同じ口から引く
（同じものが 2 通りに見えない）」と決めているので、Drafts も同じ形にする。

### 行

行の型（`Row`）は名前・絵・押すキーしか持たず、副題の欄が無い。**時刻は名前に畳む。**

```
ideas.md · 2 min ago
notes.md · yesterday
```

相対で綴り、24 時間を越えたら日付（`2026-09-07`）へ落とす。メニューは開くたびに
綴り直されるので、相対でも古びない。

**これは #309 と同じ決め。** #309（Recent の行に時刻を添える）が先に Row への載せ方を
決め、Drafts はそれに追従する。同じ一覧に 2 通りの行の形を作らない。

### 押したら

**札も本文も戻し、印を立てたまま開く。** 押されたことが許可の資格という Recent の作法
（`app/app.mbt:480-491`）と同じで、開いた瞬間から「ディスクとは違う字を持っている」が
印で言えている。人が `Mod+S` を押した所で印が落ちる。

開く前に `confirm_discard` を通る（いまの文書も控えに載っているので、失われない）。

### たずねの言葉

`Discard unsaved changes?` は嘘になる。押した後も `Drafts` から戻せる。

```
前: ask_of("Discard unsaved changes?", "Discard")
後: ask_of("Leave this document? Drafts keeps your changes.", "Leave")
```

`app/parts/asks.mbt` の `unsaved_changes` も名ごと直す。

### 言えなかったとき

控えが取れないことがある（private mode で IndexedDB が倒れる、quota を超える）。
黙らない。しらせの表に 1 語足す。

```
Couldn't keep a draft
```

未保存の `●` の意味は**変えない**。「ディスクにこの字は無い」を指し続ける。
控えが在ることは印では言わない（言うと 2 つの状態が 1 つの点に乗る）。
`beforeunload` も残す。ディスクの `.md` は古いままなので、言うことがある。

## Autosave を捨てる

| 何 | どうする |
|---|---|
| 持ち物 `mmm.autosave` | `owned` の表から外す。`prefs.sweep` が次の起動で掃く |
| Files の `Autosave` / `Save by hand` の行 | 消す |
| `App.autosave` と `set_autosave` / `toggle_autosave` | 消す |
| `docs/spec.md:468-474` | Drafts の節に書き替える |
| `app/app_wbtest.mbt` の自動保存の試験 2 本 | Drafts の試験に書き替える |

**Drafts が入ってから捨てる。** 逆にすると、安全網の無い時間ができる。

#318（他所で書き換えた `.md` を黙って上書きする）は、これで**自動では起こらなくなる**。
人が `Mod+S` を押したときだけ残るので、柵（書く前に更新時刻を見る）はそのまま段 A に置く。

## 決めてもらうこと（推しのまま進める）

| 何 | 推し |
|---|---|
| 版を切る間合い | 5 分。1 系列 3 版（直近 15 分） |
| 上限 | 20 系列 / 合計 20 MB |
| 一覧の名前 | `Drafts` |
| 立ち上がりの並び | Drafts が上、Recent が下 |
| 消す道 | `Forget all drafts` の 1 行だけ |
| 本文の置き方 | 生（gzip しない） |

## やらないこと

- **勝手に開き直さない。** 立ち上がりは今までどおり空から始まる（`docs/spec.md:475`）
- **控えからディスクへ書き戻さない。** 書くのは人
- **他のタブと取り合わない。** 系列の id は流れごとに振るので、2 つのタブが同じ鍵を
  書くことがない（#300 の形とは別）
- **OPFS は使わない。** `docs/browsers.md:113-123` が「保存層の差し替えはビルド時分岐、
  OPFS 版は別の製品」と決めている。控えは保存層ではない
- **undo の代わりにしない。** 打ち間違いを戻すのは undo（単一スタック）。
  控えは「窓ごと失った」ときの入口
